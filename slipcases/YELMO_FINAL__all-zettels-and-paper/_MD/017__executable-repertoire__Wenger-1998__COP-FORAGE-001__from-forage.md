TITLE: THE SHARED REPERTOIRE BECOMES EXECUTABLE

SOURCE: Etienne Wenger — Communities of Practice: Learning, Meaning, and Identity — Cambridge University Press, 1998 — https://doi.org/10.1017/CBO9780511803932

SOURCE URL: https://doi.org/10.1017/CBO9780511803932

PASSAGE: [PARAPHRASE] Wenger develops learning as social participation and treats practice as involving communal engagement through which participants develop shared ways of doing and making sense of their activity.

RESEARCH OBJECT: [[PROMPT-FORAGE-001]] framed prompting expertise as socially accumulated skill. The prompt community adds a computational mutation to the community-of-practice idea: a piece of repertoire can be not only described, demonstrated, remembered, or imitated but copied into the machine and executed. A shared prompt is simultaneously discourse about practice and an operational artifact that can produce another observable event.

LOCAL MOVE: Follow the parent’s “best way to learn is by looking at how other people’s prompts look” past social learning into the material status of the prompt itself. Unlike many craft tips, the shared object can often be rerun with low transcription cost.

SOURCE TERMS: social participation; practice; community; learning; meaning; identity; shared practice

WHAT BECAME STRANGE: [OUR INFERENCE] Generative-AI communities can circulate recipes that partly execute themselves. The novice does not first have to internalize the whole technique before seeing what it does; copying the artifact can generate the demonstration from which understanding is subsequently reconstructed.

QUESTION: How does apprenticeship change when a fragment of expert practice can be copied before it is understood and immediately made operational?

DEEPER QUESTION: Does executable repertoire accelerate legitimate peripheral participation, or does it create a new kind of competence in which visible performance can precede conceptual understanding?

MECHANISM: Practitioner develops prompt through repeated work → prompt and output are publicly exposed → newcomer copies or remixes prompt → model executes inherited artifact → newcomer observes consequence → modifies terms → local understanding grows through intervention rather than prior mastery.

FORMAL SHIFT: FROM: SHARED REPERTOIRE → OBSERVE / IMITATE / INTERNALIZE → PERFORM. TO: SHARED REPERTOIRE_AS_EXECUTABLE → RUN → OBSERVE CONSEQUENCE → MODIFY → PARTIAL UNDERSTANDING.

SOURCE FORMALISM: NONE; “executable repertoire” is not Wenger’s term.

OUR FORMALIZATION: [OUR FORMALIZATION — NOT SOURCE SYNTAX] EXPERT_ARTIFACT P → COPY(P) → MODEL(P) → OUTPUT → NOVICE_COMPARISON → P' → MODEL(P') → LOCAL PRACTICE

TENSION: Copyability can democratize entry while obscuring causal knowledge. A practitioner may reproduce a high-status effect without knowing which prompt components matter, whether the effect is robust, or whether the folk explanation attached to the prompt is correct.

MISSING: Empirical comparison of learning trajectories where novices receive (A) output only, (B) prompt only, (C) prompt plus explanation, and (D) an interactive prompt lineage with failed iterations.

BOUNDARY: Wenger’s source concerns communities of practice generally and does not theorize prompts or executable artifacts. The extension to executable repertoire is ours and requires empirical testing.

CITATION TRAIL: [[PROMPT-FORAGE-001]] → socially accumulated prompt craft → Wenger’s practice-as-social-participation → prompt as copyable operational artifact → next edge: test whether executable sharing changes the pace and structure of novice movement into competent practice

TEST: Give matched novice groups four forms of access to an expert image-generation workflow: final image only; prompt only; prompt plus written rationale; complete iteration history including failures. Hold model and task constant. Measure immediate imitation, transfer to novel tasks, causal understanding, and ability to diagnose breakage after a model update.
