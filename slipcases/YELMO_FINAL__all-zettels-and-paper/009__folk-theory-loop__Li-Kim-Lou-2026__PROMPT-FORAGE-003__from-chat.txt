ID: PROMPT-FORAGE-003

TITLE: A FOLK THEORY OF AI DOES NOT JUST EXPLAIN THE MACHINE; IT CHANGES THE EXPERIMENT YOU PERFORM ON IT

SOURCE: Zhuoman Li, Nuri Kim, and Chen Lou — “Into the Black Box: Laypeople’s Folk Theories About Generative Artificial Intelligence Chatbots” — Big Data & Society 13(2), 2026 — https://doi.org/10.1177/20539517261447838

PASSAGE: [PARAPHRASE] Participants formed causal theories of generative AI from buzzwords, analogies, and interaction. Those theories then shaped concrete interaction scripts such as command-like language, emotional boundary testing, persona assignment, and step-by-step prompting.

RESEARCH OBJECT: [[PROMPT-FORAGE-001]] preserved a distinction between prompt rules that work and practitioners’ possibly incorrect explanations of why they work. Li, Kim, and Lou make the relation stranger. A folk explanation is not merely a commentary laid on top of use. Believing that the system learns from conversation, mirrors emotion, behaves like a search engine, or requires commands causes users to alter what they input. The theory therefore changes the observations from which the next theory will be inferred. Prompt folklore can become an intervention loop.

LOCAL MOVE: Follow [[PROMPT-FORAGE-001]] from “operationally useful but causally inaccurate” into the mechanism through which causal stories themselves create prompt practices and new evidence.

SOURCE TERMS: folk theories; intuitive causal beliefs; social scripts; machine-like schema; human-like schema; commanding words; emotional expression; step-by-step instructions; analogy; boundary testing

WHAT BECAME STRANGE: [OUR INFERENCE] Prompt superstition can be performative. “The AI responds better when I do X” induces X; X changes the output distribution; the changed outputs become evidence for the original theory. A mistaken explanation can therefore produce genuine empirical regularities in the user’s own interaction history.

QUESTION: How can we tell whether a prompting belief describes a pre-existing property of the model or helps create the behavioral pattern users cite as evidence for that belief?

DEEPER QUESTION: When users can only know an opaque system by intervening on it, can observation ever be cleanly separated from the prompting practices generated by their prior theories?

MECHANISM: Opaque AI behavior → user constructs analogy or causal belief → belief produces a social script for prompting → altered prompts produce altered outputs → outputs are interpreted through the existing belief → belief is strengthened, revised, or transmitted → subsequent interventions change again.

FORMAL SHIFT: FROM: MODEL → OUTPUT → USER THEORY. TO: USER THEORY_t → PROMPT STRATEGY_t → MODEL OUTPUT_t → INTERPRETATION_t → USER THEORY_t+1.

SOURCE FORMALISM: The study organizes folk theories around beliefs about working mechanisms, perceived characteristics, and expectations, then examines how those theories shape interaction behavior. Participants report command-like prompting, emotional testing, detailed procedural instructions, funneling, and persona assignment; discussion among participants can also revise previously held theories.

OUR FORMALIZATION: [OUR FORMALIZATION — NOT SOURCE SYNTAX] THEORY("ANGER MAKES IT LISTEN") → ANGRY PROMPT → DIFFERENT RESPONSE → NOTICE DIFFERENCE → THEORY("ANGER WORKS") → REPEAT → LOCAL REGULARITY

TENSION: The circularity does not imply that every folk rule is false. Some user-generated theories correctly discover stable affordances. The research problem is therefore not to eliminate folklore but to distinguish discoveries about the model from regularities jointly produced by model, interface, user behavior, selective memory, and community transmission.

MISSING: Controlled experiments measuring how prior causal explanations change users’ prompting strategies and therefore observed model performance; comparison between communities exposed to different folk theories while using the identical model.

BOUNDARY: Li, Kim, and Lou study generative-AI chatbot users, not the 2022 Midjourney community. The source establishes a mechanism for folk-theory formation and action in interactive generative AI, not direct evidence that the same mechanism produced specific Midjourney prompt superstitions.

CITATION TRAIL: [[PROMPT-FORAGE-001]] → prompt expertise can coexist with inaccurate mechanism theories → Li, Kim, and Lou show folk theories generating interaction scripts and boundary tests → next edge: experimentally seed rival theories in otherwise equivalent prompting communities and observe whether different “craft traditions” emerge around the same model

TEST: Randomly assign novice users of one fixed generative model to three explanation conditions: retrieval-machine theory, stochastic-association theory, and anthropomorphic collaborator theory. Give all groups identical tasks and budgets. Record prompt syntax, iteration paths, perceived causality, and objective output quality. After several sessions, let groups exchange successful prompts. Test whether distinct prompt cultures emerge despite an identical underlying system and whether any initially false theory produces locally successful practices that perpetuate it.

PLATFORM: GENERATIVE-AI CHATBOTS / FOLK THEORY / HUMAN-AI INTERACTION
