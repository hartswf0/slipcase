Xsolla Metasites translates the hyperlink graph into a portal graph.

PASSAGE:
[QUOTE] “Portals connect diverse Metasites, forming a navigable 3D web.”

RESEARCH OBJECT:
Xsolla's Metasites proposal contains an almost literal translation of web topology into spatial topology.

WEB:
PAGE —LINK→ PAGE

METASITES:
WORLD —PORTAL→ WORLD

LOCAL MOVE:
Instead of replacing the web with a metaverse, Metasites spatializes one of the web's foundational operations: linking.

WHAT BECAME STRANGE:
A portal may simply be a hyperlink that has acquired architecture.

QUESTION:
What is the difference between clicking a link and walking through a portal?

DEEPER QUESTION:
Could a browser-native metaverse emerge not by inventing a new network topology but by giving the existing web graph embodied verbs?

MECHANISM:
<3D SITE A>
→ [PORTAL]
→ <3D SITE B>

corresponding to:

<WEB PAGE A>
→ [HYPERLINK]
→ <WEB PAGE B>

FORMAL SHIFT:
<LINK>
→ <SPATIAL REPRESENTATION OF LINK>
→ [TRAVERSE]
→ <PLACE CHANGE>

SOURCE FORMALISM:
Xsolla describes browser-accessible Unreal/WebGL experiences, interconnected portals, social layers, inventories, in-world items, and a network of Metasites.

OUR FORMALIZATION:
[OUR FORMALIZATION — NOT SOURCE SYNTAX]

HYPERLINK:
A --click--> B

PORTAL:
A --walk--> B

Both instantiate:

EDGE(A,B)

Only the interaction grammar differs.

TENSION:
Earlier “metaverse” rhetoric often imagined a successor to the web.

Metasites instead makes the web itself three-dimensional.

MISSING:
Whether portals preserve identity, inventory, permissions, and object ownership across independently created Metasites—or merely navigate between them.

BOUNDARY:
Xsolla calls the resulting system a decentralized creator-powered network, but the cited product description alone does not establish decentralization at the protocol or infrastructure-ownership level.

TEST:
For a portal crossing, measure:

IDENTITY survives?
INVENTORY survives?
URL changes?
SERVER changes?
ORIGIN changes?
AUTHORITY changes?
PERMISSIONS survive?

Then determine whether PORTAL is merely navigation or true world continuity.
