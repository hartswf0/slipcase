# X. What Refuses to Be a System

The most valuable card in a field of cultural systems may be the one that refuses admission.

Csordas's "Morality as a Cultural System?" begins from Geertz's series and concludes that morality is better treated as a modality of action crossing domains than as one system alongside religion, ideology, common sense, and art. [@csordas2013morality] This is more than a negative answer. It creates a type distinction. Some phenomena organize bounded domains; some qualify actions across domains; some provide media or infrastructural conditions; some are operations; some are trajectories; some are objects only because several practices keep coordinating their multiple versions.

Peters's media theory makes a similar refusal from another direction. Media can be environments and containers of possibility. [@peters2015marvelous] Treating them simply as another bounded cultural system misses their role in making many other systems possible. Star and Ruhleder's relational infrastructure does the same: infrastructure is not a thing one can identify once and for all but a status achieved in relation to practice. [@starruhleder1996steps]

Mol's atherosclerosis pushes harder still. Different medical practices do not necessarily provide several perspectives on one stable disease; they enact partially different versions that have to be coordinated. [@mol2002body] The apparent unity of the object is an accomplishment. This creates a problem for every theory that assumes one canonical state underneath several representations. Sometimes the world does not present one state waiting to be read correctly.

Ingold's lines offer a complementary warning about discretization. [@ingold2007lines] If the analyst turns becoming into a sequence of finished states, the clarity of the model may be purchased by destroying the phenomenon. A runtime vocabulary is useful only when it can preserve an uncompiled residue: aspects of experience, gesture, ambiguity, continuity, and multiplicity that should not be forced into state-machine form.

The field therefore needs failure criteria not only for cultural systems but for the analytical language used to describe them. If "runtime" merely renames what a strong ethnographic account already showed, discard it. If every objection can be absorbed as one more module, discard it. If code-like notation produces visual precision without empirical discrimination, discard it. If the framework cannot say that some phenomena are modalities, media, trajectories, or multiple enactments rather than systems, discard it.

A theory that admits everything explains nothing.
