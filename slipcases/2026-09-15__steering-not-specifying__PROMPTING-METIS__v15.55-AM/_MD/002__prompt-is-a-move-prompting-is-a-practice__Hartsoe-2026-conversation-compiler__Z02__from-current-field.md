TITLE: The prompt is a move; prompting is a practice
ORIGINAL ID: Z02
TYPE: NEW ZETTEL

CLAIM
An isolated prompt is only one move in a larger practice of perception, intervention, feedback, repair, and continuation.

EVIDENCE
The user frames skilled action as observing what actually happened and altering the next action accordingly. This shifts the unit of analysis from a prompt string to an unfolding practice.

TENSION
Prompt engineering discourse often searches for a self-sufficient instruction that eliminates the need for situated correction.

QUESTION
What analytical methods become possible when prompting is studied longitudinally as a practice rather than atomically as text?
