TITLE: The event changes under a description
ORIGINAL ID: Z08
TYPE: NEW ZETTEL

CLAIM
One physical event can be truthfully described in several ways, while intentional action attaches only under some descriptions.

EVIDENCE
Anscombe’s Intention develops intentional action through the applicability of the “Why?” question and layered descriptions of the same doing. This matters for generative outputs whose causal history admits several descriptions.

TENSION
Post hoc redescription can illuminate action but can also become an alibi if actors choose descriptions strategically.

QUESTION
How should systems preserve enough provenance to contest convenient retrospective descriptions of action?
