CALLSHOT-FIELD-004

TITLE:
GENERATING AN OUTPUT CAN BE AN EPISTEMIC ACTION: THE IMAGE EXISTS TO MAKE THE NEXT THOUGHT POSSIBLE.

SOURCE:
David Kirsh and Paul Maglio, “On Distinguishing Epistemic from Pragmatic Action,” Cognitive Science 18(4), 1994, 513–549. DOI 10.1207/s15516709cog1804_1. SOURCE URL: https://onlinelibrary.wiley.com/doi/10.1207/s15516709cog1804_1

PASSAGE:
[QUOTE]
“actions that use the world to improve cognition.”

RESEARCH OBJECT:
A GENERATED ARTIFACT MAY BE VALUABLE PRIMARILY BECAUSE IT CHANGES THE OPERATOR’S COGNITIVE STATE.

LOCAL MOVE:
Kirsh and Maglio distinguish pragmatic actions that directly advance an external goal from epistemic actions that transform the world to simplify cognition. This gives a precise reading of generations used to discover what to ask for next.

SOURCE TERMS:
“epistemic action” · “pragmatic action” · “improve cognition” · “uncover information”

WHAT BECAME STRANGE:
A generation that is thrown away may still be productive if it reveals a distinction, contradiction, or possibility the user could not compute mentally.

QUESTION:
How many generative actions are really probes rather than products?

DEEPER QUESTION:
Does cheap generation change creativity mainly by lowering the cost of external cognitive experimentation rather than final production?

MECHANISM:
DIFFICULT INTERNAL PROBLEM → EXTERNAL ACTION → NEW PERCEPTUAL STATE → REDUCED COGNITIVE BURDEN → NEXT ACTION.

FORMAL SHIFT:
OUTPUT AS PRODUCT → OUTPUT AS TEMPORARY COGNITIVE INSTRUMENT.

SOURCE FORMALISM:
[PARAPHRASE]
Kirsh and Maglio use Tetris to show that some external actions improve cognition rather than directly implementing the task goal.

OUR FORMALIZATION:
[OUR FORMALIZATION — NOT SOURCE SYNTAX]
P_t → G(P_t) = O_t → SEE(O_t) → ΔK_t → P_t+1. Value(O_t) may equal information gain, not artifact quality.

TENSION:
Unlike rotating a Tetris piece, generation manufactures a new synthetic object from which the user then learns. The probe is also a construction.

MISSING:
Empirical classification of generative outputs by downstream cognitive function.

BOUNDARY:
The paper does not discuss generative AI; this is a formal analogy, not genealogy.

CITATION TRAIL:
[[MJ-JOSHUA-002-A]] → Kirsh & Maglio → output changes cognitive state → connects search practice to a theory of action.

TEST:
Code every output in a real generative session as final-use, hypothesis test, unanticipated discovery, category formation, or repetition. Test whether prompt changes are disproportionately caused by epistemic outputs.

PLATFORM:
Cognitive Science · generative design
