RESEARCH OBJECT:
PRACTITIONERS ORGANIZE PROMPT WORK AS BRANCHING EXPLORATION OF A DESIGN SPACE.

LOCAL MOVE:
Joshua describes a core phrase surrounded by artist substitutions, building types, character types, and increasingly specific combinations. The operative unit is a lineage of mutations, not one prompt.

SOURCE TERMS:
“core phrase” · “mind map” · “branches” · “sub nodes” · “design space” · “different combinations”

WHAT BECAME STRANGE:
The chat interface records a sequence, while the practitioner thinks in a tree. Linear history hides the actual search structure.

QUESTION:
What should a prompt interface preserve if the work is genealogical rather than conversational?

DEEPER QUESTION:
Could discarded prompt branches be reusable creative infrastructure for later users rather than dead history?

MECHANISM:
CORE PHRASE → MUTATION → SAMPLE → JUDGE → BRANCH / ABANDON → FURTHER MUTATION.

FORMAL SHIFT:
PROMPT HISTORY AS LIST → PROMPT PRACTICE AS EXECUTABLE GENEALOGY.

SOURCE FORMALISM:

Joshua explicitly compares his process to a mind map with a central phrase, branches, and subnodes.
