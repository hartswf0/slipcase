RESEARCH OBJECT:
DURABLE EXPERTISE MAY BE EPISTEMIC DISCIPLINE RATHER THAN STABLE PROMPT SYNTAX.

LOCAL MOVE:
[[MJ-2022-009]] treated rapid obsolescence as a threat to prompt expertise. Shambibble’s phrase “studied ignorance” suggests another reading. The expert may be the person who knows which claims are local, which are tested, which are hunches, which variables remain uncontrolled, and when a previously learned trick has expired.

SOURCE TERMS:
“absolutely fucking nothing in six months”

“there’s not a lot we know”

“empirically”

WHAT BECAME STRANGE:
The shortest-lived part of prompt practice may be the prompt itself. The longer-lived skill is knowing how little a successful output permits you to infer.

QUESTION:
What remains of prompt expertise after every model-specific trick has been invalidated?

DEEPER QUESTION:
Could prompt expertise be defined as a protocol for producing and retiring local knowledge rather than possession of a repertoire of magic words?

MECHANISM:
Observe behavior. Form local hypothesis. Control what can be controlled. Repeat. Mark uncertainty. Teach only bounded claims. Re-test after version change. Retire rules that no longer reproduce.

FORMAL SHIFT:
PROMPT EXPERTISE AS RECIPE COLLECTION
→ VERSION CHANGE
→ OBSOLESCENCE

versus

PROMPT EXPERTISE AS TEST DISCIPLINE
→ VERSION CHANGE
→ RETEST
→ UPDATED LOCAL KNOWLEDGE

SOURCE FORMALISM:
Anthropic’s current prompt-engineering overview assumes defined success criteria and empirical tests before prompt optimization, reinforcing an evaluation-first rather than incantation-first practice.

OUR FORMALIZATION:
[OUR FORMALIZATION — NOT SOURCE SYNTAX]

DURABLE META-SKILL = discriminate OBSERVATION / HUNCH / LOCAL REGULARITY / MECHANISM / EXPIRED RULE.

TENSION:
Formal evaluation can itself become ritual if test cases do not represent the real use or if benchmarks remain fixed while models and tasks change.

MISSING:
Longitudinal biographies of prompt practitioners showing which skills transferred across model generations and which did not.

BOUNDARY:
The transcript supports Shambibble’s epistemic stance; it does not establish that this stance predicts better performance without comparative evidence.
