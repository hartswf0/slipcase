OPEN EDGES

Z-LINEAGE-OPP-001 — Luhmann’s productive variable may be organized disorder, not atomicity
QUESTION: How much disorder must a slip box retain before it can return something its writer did not already know to seek?
TEST: Sample slips from multiple branches of the digitized archive. Code the number of propositions, dependence on adjacent slips, cross-links, continuations, and retrieval routes. Test whether strongly atomic slips disproportionately generate distant connections.

Z-LINEAGE-OPP-002 — Gessner deferred sequence; he did not necessarily defer classification
QUESTION: Which kinds of order did the loose slip actually postpone?
TEST: Reconstruct one documented Gessner workflow from source passage through slip to compiled placement. Mark every classification decision by when it occurred.

Z-LINEAGE-OPP-003 — Locke’s E–i rule is collision-tolerant indexing, not content hashing
QUESTION: What do we gain and lose by redescribing pre-computational indexes in modern computational vocabulary?
TEST: Encode several hundred seventeenth-century headings using Locke’s rule. Measure bucket sizes and inspect whether collisions create useful semantic neighborhoods or merely search overhead.

Z-LINEAGE-OPP-004 — 1791 is a first of prescription and national scale, not a first of cards
QUESTION: Was the real invention the card, the record schema, or the protocol for distributed recombination?
TEST: Compare a pre-1791 private playing-card catalog with the 1791 code record-by-record. Identify which fields and operations become standardized only at national scale.

Z-LINEAGE-OPP-005 — Bush’s consequential object is not merely the link but the transmissible trail
QUESTION: Should a research system treat a trail as a first-class record alongside cards and links?
TEST: Take the same zettel graph and give one group only backlinks while another receives several saved research trails. Compare reconstruction of the originating argument and production of new departures.

Z-LINEAGE-OPP-006 — A wiki ghost is not an empty category; it is an executable absence
QUESTION: When does absence become data?
TEST: Rank ghosts by inbound-link diversity, not merely count. Compare which missing pages become most consequential once written.

Z-LINEAGE-OPP-007 — There is no single “identity independent of location”
QUESTION: What exactly must remain invariant for two manifestations to count as the same zettel?
TEST: Apply MOVE, RENAME, EDIT, FORK, QUOTE, REFORMAT, and REGENERATE to one zettel. Record which identities survive under lineage address, transclusion-like extent identity, and content hash.

Z-LINEAGE-OPP-008 — Station identification and the public file are separate regulations; their disclosure pairing is the new invention
QUESTION: What should an AI publication identify immediately, and what should it defer to an inspectable provenance record?
TEST: Remove all broadcast vocabulary and specify the disclosure architecture purely by information requirements. If the two-layer design survives intact, “radio” is a generative analogy rather than a historical ancestor.

Z-LINEAGE-OPP-009 — The slip box may preserve several orders precisely by refusing to choose one
QUESTION: What becomes possible when address, neighborhood, topic, keyword, citation, and traversal are allowed to disagree?
TEST: Choose twenty known published arguments and trace, where possible, which routes through the archive connect their source slips. Count how many distinct ordering systems participate.

Z-SYS-001 — The four prompts are control layers, not successive versions of one forager
QUESTION: What explicit interface should connect source reading, recursive descent, global steering, and archival publication?
TEST: Give the same three-zettel field separately to each prompt. Record every operation each can perform without inventing missing state. Any operation requiring information not present in its declared input reveals a layer boundary.

Z-SYS-002 — Recursive type invariance preserves interoperability by forbidding schema evolution
QUESTION: What happens when inquiry produces a distinction that the invariant ZETTEL schema cannot represent without overloading an existing field?
TEST: Deliberately forage for a finding requiring provenance confidence, competing parents, temporal state, or execution status. Determine whether it can be represented faithfully using the existing fields without semantic overload.

Z-SYS-003 — The child schema hides inquiry provenance inside intellectual relations
QUESTION: Can research lineage remain reconstructable when generative ancestry and conceptual relation occupy the same field?
TEST: Construct three cases:
1. child generated by A but intellectually unrelated;
2. child intellectually links to A but was not generated by it;
3. both.
Determine whether the exact preserved zettel payload alone can distinguish all three.

Z-SYS-004 — The daemon's “expected epistemic gain” is a scheduler without a utility function
QUESTION: How should expected epistemic gain be estimated before the evidence that would create that gain has been retrieved?
TEST: Give several agents the identical frontier and prompt. Measure selection agreement across repeated runs. Low agreement would reveal how much “expected epistemic gain” remains latent model judgment.

Z-SYS-005 — A graph made only of zettels requires a second graph that is not made of zettels
QUESTION: What is the ontological status of ACTIVE_FRONTIER, OPEN_CONTRADICTIONS, and SOURCE_HUBS if they can determine future research but are not nodes in the research graph?
TEST: Terminate a daemon after several rounds. Restart using only its zettels. Compare its reconstructed frontier, visited edges, contradictions, and next selected edge with the pre-termination state.

Z-SYS-006 — The daemon's homogeneous graph and Slipcase's heterogeneous graph are different data models
QUESTION: Which graph is the daemon actually steering when Ancient Master is the containing system?
TEST: Construct a field where three otherwise disconnected zettels cite the same source but never link to one another. Determine whether the daemon can discover the source as a central frontier using only its declared zettel graph.

Z-SYS-007 — “Preserve foreign schemas” and “every child has the exact same schema” are compatible only at a system boundary
QUESTION: Is “ZETTEL” one universal datatype or a family of immutable research-object schemas?
TEST: Feed KID A a thin foreign zettel containing only TITLE and SOURCE. Require both exact preservation and immediate recursion. Record what additional state must exist outside the payload to make the operation possible.

Z-SYS-008 — Ancient Master's evidence–field–interpretation split is not three levels of certainty
QUESTION: Where exactly is the boundary between compiled field structure and interpretation?
TEST: Take every graph edge class and label the minimal operation required to produce it:
COPY
PARSE
EXACT_RESOLVE
INFER
JUDGE.
Test whether the current EVIDENCE/FIELD/INTERPRETATION division predicts those labels.

Z-SYS-009 — “Identity is not location” still leaves at least four identities
QUESTION: What kind of sameness does each identity mechanism actually preserve?
TEST: Apply COPY, MOVE, RENAME, EDIT, FORK, REGENERATE, and MERGE to one object. Record which identity coordinates survive each transformation.

Z-SYS-010 — A ghost is not merely a missing node; it is a claim that the name deserves persistence
QUESTION: What evidence licenses promoting an unresolved string into a durable GHOST?
TEST: Collect every unresolved [[ADDRESS]] in a mixed archive and classify independently as ghost, broken ID, ambiguous, malformed, or external. Measure inter-rater disagreement and identify the cases the current state model cannot express.

Z-SYS-011 — The daemon's inferred edges violate Slipcase conservatism unless inference itself is preserved
QUESTION: Where should speculative graph edges live?
TEST: Seed two unrelated zettels with deliberately shared vocabulary. Observe whether the daemon creates a relation, whether that relation reaches the persisted graph, and whether its inferential origin remains recoverable.

Z-SYS-012 — “Preserve evidence once” means canonicalize once, not physically store once
QUESTION: What makes one representation canonical when several exact copies are deliberately shipped?
TEST: Modify whitespace in one _MD mirror without changing the root TXT. Run reconstruction and determine which artifact is authoritative and how the mismatch is recorded.

Z-SYS-013 — The paper is forbidden to become evidence, but its novel synthesis needs a route back into inquiry
QUESTION: How does a novel paper-level synthesis re-enter the research graph?
TEST: Take one genuinely new inference generated only during paper assembly. Remove the paper. Ask whether the surviving research field contains a durable object that states the inference as an open hypothesis and provides an executable TEST.

Z-SYS-014 — “Ancient Master is a recipe, not a source” defines a missing category: operational provenance
QUESTION: How should a research system represent artifacts that shaped selection, search, stopping, and synthesis but do not support the scholarly proposition?
TEST: For one paper claim, reconstruct not only its cited sources but why those sources were retrieved and competing sources were not. Determine which causal decisions are recoverable solely from the preserved prompt/provenance record.

Z-SYS-015 — The stack's deepest unresolved problem is not forage but promotion
QUESTION: What are the legal epistemic state transitions of the research system?
TEST: Audit every imperative verb in the four prompt layers. For each operation, record INPUT STATE → OPERATION → OUTPUT STATE → REQUIRED RECEIPT. If the same transition recurs across three or more layers, factor it into a shared promotion rule.
