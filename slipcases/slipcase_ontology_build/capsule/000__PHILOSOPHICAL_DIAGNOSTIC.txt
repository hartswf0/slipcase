THE PHILOSOPHICAL DIAGNOSTIC

THE DEAD RUBBLE

- “The prompt is not the program; the lineage is the program.” Too symmetrical. It replaces one stable object with another.
- “There are four causal accounts.” Useful analytic scaffolding, but dead if promoted into a complete ontology.
- “Record more provenance and the problem becomes tractable.” False comfort. The question of what belongs to the object survives better logging.
- “Context engineering solves prompt engineering.” It solves engineering problems by enlarging the object; it does not settle where the object ends.
- “Prompt = language.” Soft prompting breaks this.
- “Prompt = conditioning.” Too broad; almost every consequential input becomes a prompt.
- “Prompt = specification.” Explicit specification can interfere with control.
- “Prompt = cause.” The visible prompt can be only one situated resource among several.

THE WARM SEED

The prompt is both stubbornly real and ontologically insufficient.

Changing words can change worlds. Yet the words never carry their force alone.

The field needs the prompt to be a bounded thing because experiments, datasets, repositories, citations, version histories, and methods need objects. The system keeps answering with an event.

THE UNSAID

There may be no non-arbitrary place where “the prompt” ends and “the conditions under which it means” begin.

If we thicken the prompt until it contains its causal conditions, the prompt disappears into execution.

If we keep it thin enough to remain a prompt, we must surrender the claim that it is the whole causal object.

The mystery is not whether words matter.

It is where their mattering resides.

APHORISTIC CORE

1. A prompt is easiest to identify before execution and hardest to identify after it has worked.
2. The text survives. The conditions that made it an instruction do not.
3. Two saved strings can be identical while their acts are not.
4. A soft prompt is called a prompt where language has vanished.
5. We keep the noun by changing what the noun names.
6. The instruction missing from the text may still be present in the model.
7. The instruction present in the text may never become present in the artifact.
8. More specification can produce less obedience.
9. We save the sentence and call the experiment reproducible.
10. The prompt is not nothing. If it were nothing, changing it would do nothing.
11. The prompt is not the whole thing. If it were the whole thing, keeping it fixed would keep the act fixed.
12. To make the prompt causally adequate, we enlarge it until it is no longer a prompt.
13. A taxonomy can tell us what is written without telling us what acted.
14. “The model followed the prompt” is often a retrospective description of correspondence, not a located mechanism.
15. The prompt is the name we give to the part of the cause we can see.
