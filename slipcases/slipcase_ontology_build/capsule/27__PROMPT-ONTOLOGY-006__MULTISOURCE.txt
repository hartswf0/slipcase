ZETTEL

ID:
PROMPT-ONTOLOGY-006

TITLE:
The prompt has a boundedness–causality dilemma: the more causally adequate it becomes, the less it remains a prompt.

SOURCE:
MULTISOURCE — Basmov, Goldberg & Tsarfaty 2026; Mei et al. 2025; Lester, Al-Rfou & Constant 2021; Suchman 1987 — SOURCE URLs: https://aclanthology.org/2026.law-main.19/ ; https://arxiv.org/abs/2507.13334 ; https://arxiv.org/abs/2104.08691 ; https://www.cambridge.org/core/books/humanmachine-reconfigurations/9D53E602BA9BB5209271460F92D00EFE

PASSAGE:
[OUR INFERENCE] Recent prompt scholarship supplies incompatible but individually useful identity conditions: prompt as linguistic text; prompt as dynamic context component; prompt as continuous learned conditioning; prompt as software artifact. Suchman’s distinction between plans and situated action provides an older warning against substituting an available representation for the event it helps organize.

RESEARCH OBJECT:
BOUNDEDNESS–CAUSALITY DILEMMA.

A thin prompt is bounded enough to save, diff, cite, and version but does not contain all variables that determine execution.

A thick prompt absorbs those variables and becomes more causally adequate, but expands toward the entire situated execution event.

LOCAL MOVE:
Stop asking “what is the real prompt?” Ask whether one object can simultaneously satisfy the field’s demands for PORTABILITY, IDENTITY, and CAUSAL ADEQUACY.

SOURCE TERMS:
linguistic object
context engineering
soft prompt
situated action
artifact
conditioning

WHAT BECAME STRANGE:
Every successful attempt to repair the prompt by adding what was missing makes the original prompt less visible inside the repaired object.

QUESTION:
Is there a non-arbitrary stopping rule for the boundary of a prompt?

DEEPER QUESTION:
What kind of scientific object is the prompt if no single boundary preserves both its identity and its causal adequacy?

MECHANISM:
Behaviorally consequential variables repeatedly appear outside the visible inscription. Incorporating them increases explanatory coverage while eroding the boundedness needed for object identity. Leaving them outside preserves the object while turning “the prompt caused the behavior” into an incomplete attribution.

FORMAL SHIFT:
FROM:
PROMPT = OBJECT WITH FIXED BOUNDARY

TO:
PROMPT = CONTESTED BOUNDARY AROUND A SITUATED CONTROL EVENT.

SOURCE FORMALISM:
NONE — this zettel synthesizes distinctions from multiple sources and does not attribute this formal dilemma to them.

OUR FORMALIZATION:
[OUR FORMALIZATION — NOT SOURCE SYNTAX]

Let P_k be prompt definitions of increasing thickness.
Let C(P_k) = causal coverage.
Let B(P_k) = boundedness / portability as a discrete artifact.

Observed research pressure suggests:
adding consequential execution conditions tends to increase C(P_k) while decreasing B(P_k).

The open question is whether some P* preserves enough of both to justify “prompt” as a causal research unit.

TENSION:
The dilemma may be partly methodological rather than ontological. Researchers routinely use partial causal variables without requiring them to contain the entire event. A prompt might remain a legitimate treatment variable even if it is not a sufficient cause. The problem would then be overclaiming, not objecthood itself.

MISSING:
A theory of prompt identity that explicitly distinguishes necessary, sufficient, manipulable, archival, and explanatory properties.

BOUNDARY:
This is a compiler synthesis. None of the cited sources states the boundedness–causality dilemma in this form.

TEST:
Construct nested definitions of “same prompt” from thin text identity to full execution-state identity. For a large repeated-run corpus, quantify how predictive each identity definition is of behavioral equivalence and how portable/reconstructible it remains. Search for a stable intermediate boundary; failure to find one strengthens the dilemma.
