Open index.html and select Download rebuild kit for a ZIP encoded within the page. Extract it, then copy the standalone index.html into its root. For scripted reconstruction use python3 _SLIPCASE/recover.py index.html restored. Existing files in the destination are rejected. To regenerate visual derivatives from source cards, run python3 _SLIPCASE/compiler.py in the original runtime or adapt its output path. The compiler uses bundled input copies and standard Python libraries. The recovery test compares the downloaded standalone HTML with the ZIP from this checkpoint.
