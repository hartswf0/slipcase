ID:
IMG-JEPA-04-A-A

TITLE:
An image must leave something out to remain an image

SOURCE:
Plato — Cratylus — 432b–433a — translated by David Horan

PASSAGE:
[QUOTE] “Would there then be Cratylus and his image, or would there be two Cratyluses?”

RESEARCH OBJECT:
Omission as a condition of representation, with a separate question about which omissions count as errors.

LOCAL MOVE:
Socrates imagines a god reproducing Cratylus down to his interior, warmth, motion, soul, and intelligence. Cratylus accepts that the result would be two Cratyluses. Socrates uses this concession to reopen what correctness can mean for an image, then carries the argument into names and sentences.

SOURCE TERMS:
Image, imitation, correctness, name, impression.

WHAT BECAME STRANGE:
[OUR INFERENCE] The question for imagetext is more exact than how much of the object can survive translation. Some differences make the description usable as a description. Others remove the very feature it was meant to bring forward. Counting omissions treats those cases alike.

QUESTION:
Can a description become more exact by omitting a true feature?

DEEPER QUESTION:
Does correctness belong to the description by itself, or to what a reader can do with that description in a particular situation?

MECHANISM:
Socrates first tests complete resemblance by asking what kind of thing it would produce. He then allows that a name or sentence can contain an unsuitable element and still name or speak of its object. Identifying what the description concerns and judging how well it describes it become separable acts.

FORMAL SHIFT:
NONE

SOURCE FORMALISM:
NONE

OUR FORMALIZATION:
[OUR FORMALIZATION — NOT SOURCE SYNTAX]
For each description, distinguish reference, accuracy of individual claims, and adequacy for the reader’s task. Score each independently.

TENSION:
A sparse description may identify the right image while omitting a crucial relation. A detailed description with one false claim may still let the reader reconstruct the scene more accurately. A single alignment score can rank either one first.

MISSING:
A criterion for deciding which omissions matter before comparing descriptions.

BOUNDARY:
The doubling argument concerns complete duplication. The JEPA theorem concerns alignment of embeddings up to rotation under specified assumptions. The comparison opens a question about selective representation without equating the two kinds of sameness.

CITATION TRAIL:
[[IMG-JEPA-04-A]] → Cratylus 432b–433a → Mitchell’s account of the addressee in Ekphrasis and the Other §18.

TEST:
Use one image and two tasks: identify it among alternatives, then reconstruct one spatial relation. Compare a sparse accurate caption, a detailed caption with one false claim, and a caption that omits the diagnostic relation. Ask which caption is best under each task and which error causes each reversal.
