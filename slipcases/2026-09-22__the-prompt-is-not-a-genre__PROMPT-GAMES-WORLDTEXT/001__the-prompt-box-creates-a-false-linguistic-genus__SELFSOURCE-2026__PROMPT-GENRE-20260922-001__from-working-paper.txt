TITLE:
The prompt box creates a false linguistic genus

SOURCE:
Watson Hartsoe, The Prompt Is Not a Genre: Language Games, Operative Ekphrasis, and Worldtext, Working Paper, 22 September 2026.

SOURCE URL:
https://github.com/hartswf0/slipcase/blob/main/slipcases/2026-09-22__the-prompt-is-not-a-genre__PROMPT-GAMES-WORLDTEXT/the-prompt-is-not-a-genre__2026-09-22.pdf

PASSAGE:
[OUR SYNTHESIS]\nCommands, questions, scores, commissions, edits, probes, constraints, and conversations now enter through one rectangular field and are all named prompts.

RESEARCH OBJECT:
[OUR INFERENCE]\nPROMPT IS AN INTERFACE CATEGORY BEFORE IT IS A LINGUISTIC GENRE.

LOCAL MOVE:
Use Ryle's category-mistake caution to separate the name of the input widget from the practice that gives an utterance force.

SOURCE TERMS:
prompt; interface category; language game; aperture

WHAT BECAME STRANGE:
The same UI can conceal different executors, success conditions, worlds, and evidentiary standards.

QUESTION:
What does the word prompt hide when a single interface accepts heterogeneous linguistic acts?

DEEPER QUESTION:
Can a history of prompting be written as a history of interfaces collapsing previously separate language games?

MECHANISM:
A common input surface induces users and researchers to nominalize distinct practices as one object.

FORMAL SHIFT:
SAME_STRING_SURFACE does not imply SAME_OPERATION.

SOURCE FORMALISM:
[OUR SYNTHESIS — NOT SOURCE FORMALISM]

OUR FORMALIZATION:
PROMPT_SURFACE = UNION(instruction, score, query, probe, edit, commission, conversation, constraint, plan, performance, gesture, program).

TENSION:
The shared surface also creates genuinely new hybrid practices, so interface accident does not mean historical insignificance.

MISSING:
Comparative empirical study of the same utterance routed through different interaction regimes.

BOUNDARY:
This card states the working paper's argument; it is not independent evidence.

CITATION TRAIL:
Ryle category caution -> prompt box -> heterogeneous games -> interface category.

TEST:
Present identical text in several systems with different rules and compare what counts as a successful continuation.

Prompting; language games; interface theory; operative humanities
