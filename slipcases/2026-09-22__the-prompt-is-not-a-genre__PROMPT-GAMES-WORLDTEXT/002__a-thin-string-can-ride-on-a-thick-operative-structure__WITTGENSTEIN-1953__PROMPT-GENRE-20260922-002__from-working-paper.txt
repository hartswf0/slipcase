TITLE:
A thin string can ride on a thick operative structure

SOURCE:
Ludwig Wittgenstein, Philosophical Investigations, 4th ed., 1953/2009, §§2, 7.

SOURCE URL:
https://plato.stanford.edu/entries/wittgenstein/

PASSAGE:
[PARAPHRASE]\nIn the builder's language-game, calls such as block, pillar, slab, and beam work within an already organized activity between builder and assistant.

RESEARCH OBJECT:
[OUR INFERENCE]\nLEXICAL THINNESS CAN COEXIST WITH OPERATIVE THICKNESS.

LOCAL MOVE:
Move prompt theory away from the isolated text string toward the practice that supplies roles, objects, permissions, and expected continuations.

SOURCE TERMS:
language-game; builder; slab; use

WHAT BECAME STRANGE:
The builder does not verbalize the ontology, permissions, or worksite state because the game carries them.

QUESTION:
How little language is needed when the game supplies the missing structure?

DEEPER QUESTION:
Which parts of modern prompt verbosity compensate for absent shared state rather than genuine linguistic complexity?

MECHANISM:
Established practice externalizes assumptions that would otherwise have to be stated in the utterance.

FORMAL SHIFT:
THIN(move) + THICK(game) -> EXECUTABLE_CONTINUATION.

SOURCE FORMALISM:
[PARAPHRASE]\nMeaning is approached through use within language-games rather than by treating words as independently self-sufficient labels.

OUR FORMALIZATION:
Effective input = move + inherited game state.

TENSION:
LLM interfaces often lack a stable shared practice, forcing users to restate what a worksite would ordinarily carry.

MISSING:
Operational comparison of minimal commands in persistent versus stateless environments.

BOUNDARY:
Wittgenstein is not writing about prompting or AI.

CITATION TRAIL:
Wittgenstein builder -> Slab! -> situated continuation -> prompt as move.

TEST:
