TITLE:
Operative ekphrasis begins when description enters an execution relation

SOURCE:
Homer, Iliad, Book 18, Shield of Achilles episode. W. J. T. Mitchell, Picture Theory: Essays on Verbal and Visual Representation, 1994.

SOURCE URL:
https://www.perseus.tufts.edu/hopper/text?doc=Hom.%20Il.%2018

PASSAGE:
[OUR SYNTHESIS FROM SOURCES]\nThe Shield of Achilles supplies a canonical description repeatedly reconstructed by later artists and makers; image-text theory complicates any clean separation between verbal and visual representation.

RESEARCH OBJECT:
[OUR INFERENCE]\nOPERATIVE EKPHRASIS = DESCRIPTION THAT PARTICIPATES IN CONSTRUCTING, MODIFYING, OR NAVIGATING WHAT IT DESCRIBES.

LOCAL MOVE:
Name the threshold where descriptive content crosses into an apparatus of realization.

SOURCE TERMS:
ekphrasis; Shield of Achilles; imagetext; realization

WHAT BECAME STRANGE:
Description can be neither mere depiction nor direct command yet still organize material or computational production.

QUESTION:
When does description stop being only representational and become part of the operation that produces its object?

DEEPER QUESTION:
What conditions distinguish operative ekphrasis from ordinary vivid description or imperative control?

MECHANISM:
Descriptive relations are mapped by an interpreter into an operational substrate whose result can be inspected.

FORMAL SHIFT:
DESCRIPTION -> INTERPRETER -> OPERATIONAL_SUBSTRATE -> RESULT.

SOURCE FORMALISM:
[NO SOURCE FORMALISM]

OUR FORMALIZATION:
Operative ekphrasis requires descriptive content plus an execution relation; vividness alone is insufficient.

TENSION:
A generated output can invite retrospective rationalization unless the description exposes challengeable relations.

MISSING:
Boundary cases between ekphrasis, specification, instruction, and score.

BOUNDARY:
The term operative ekphrasis is Hartsoe's; Homer and Mitchell do not use it.

CITATION TRAIL:
Homeric shield -> imagetext -> executable description -> operative ekphrasis.

TEST:
For candidate cases, identify which descriptive relations are mapped into which operational substrate and how compliance is inspected.

PLATFORM:
Ekphrasis; visual studies; operative humanities
