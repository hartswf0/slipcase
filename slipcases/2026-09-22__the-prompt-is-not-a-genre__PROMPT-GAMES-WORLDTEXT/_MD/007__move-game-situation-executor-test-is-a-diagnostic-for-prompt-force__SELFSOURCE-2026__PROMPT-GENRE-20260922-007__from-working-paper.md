TITLE:
Move game situation executor test is a diagnostic for prompt force

SOURCE:
Watson Hartsoe, The Prompt Is Not a Genre: Language Games, Operative Ekphrasis, and Worldtext, Working Paper, 22 September 2026.

SOURCE URL:
https://github.com/hartswf0/slipcase/blob/main/slipcases/2026-09-22__the-prompt-is-not-a-genre__PROMPT-GAMES-WORLDTEXT/the-prompt-is-not-a-genre__2026-09-22.pdf

PASSAGE:
[OUR SYNTHESIS]\nPrompt failures can be separated by asking what move was made, what game made it an act, what situation supplied state, what executor was entitled to continue it, and what test judged adequacy.

RESEARCH OBJECT:
[OUR FORMALIZATION]\nPROMPT = MOVE + GAME + SITUATION + EXECUTOR + TEST.

LOCAL MOVE:
Turn the paper's heterogeneous examples into a reusable analytic instrument.

SOURCE TERMS:
move; game; situation; executor; test

WHAT BECAME STRANGE:
Many apparent wording failures are actually mismatches in executor authority, state, or evaluation.

QUESTION:
At which component did a failed prompt interaction actually break?

DEEPER QUESTION:
Can the tuple predict which interface intervention will outperform a text rewrite?

MECHANISM:
The diagnostic distributes operative force across the interaction rather than localizing it in the sentence.

FORMAL SHIFT:
P* = <M,G,S,E,T>.

SOURCE FORMALISM:
[OUR FORMALIZATION — NOT SOURCE SYNTAX]

OUR FORMALIZATION:
adequacy(output) is evaluated relative to T under G and S, not by linguistic plausibility alone.

TENSION:
The five terms are analytic conveniences, not a complete ontology.

MISSING:
Validation across diverse prompt tasks and multimodal systems.

BOUNDARY:
Derived by Hartsoe from the paper's comparative cases.

CITATION TRAIL:
builder + SHRDLU + Put-That-There + thick description -> five-part diagnostic.

TEST:
Code failures across a corpus by component; test whether repairs targeted to that component outperform prompt-only edits.

PLATFORM:
Prompt theory; HCI; diagnostics
