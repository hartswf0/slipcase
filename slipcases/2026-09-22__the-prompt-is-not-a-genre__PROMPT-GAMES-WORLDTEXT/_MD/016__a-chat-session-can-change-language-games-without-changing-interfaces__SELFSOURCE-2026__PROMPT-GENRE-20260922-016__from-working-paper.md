TITLE:
A chat session can change language games without changing interfaces

SOURCE:
Watson Hartsoe, The Prompt Is Not a Genre: Language Games, Operative Ekphrasis, and Worldtext, Working Paper, 22 September 2026.

SOURCE URL:
https://github.com/hartswf0/slipcase/blob/main/slipcases/2026-09-22__the-prompt-is-not-a-genre__PROMPT-GAMES-WORLDTEXT/the-prompt-is-not-a-genre__2026-09-22.pdf

PASSAGE:
[OUR SYNTHESIS]\nA user may begin with a query, turn the answer into a plan, convert the plan into code, edit the code, constrain the output, and finally perform the system live while the interface remains a chat window.

RESEARCH OBJECT:
[OUR INFERENCE]\nTHE RESEARCH OBJECT IS THE TRACK CHANGE: WHEN DO THE RULES OF THE INTERACTION BECOME DIFFERENT RULES?

LOCAL MOVE:
Shift from static prompt classification toward transitions among language games.

SOURCE TERMS:
drift; track change; query; plan; program; edit; constraint; performance

WHAT BECAME STRANGE:
The interface can remain visually constant while the criteria of a valid move change beneath it.

QUESTION:
At which turn did the interaction stop being one game and become another?

DEEPER QUESTION:
Can game drift be detected from changes in executor, allowable actions, or evaluation criteria rather than from wording alone?

MECHANISM:
Sequential interaction accumulates commitments and artifacts that alter what later utterances can do.

FORMAL SHIFT:
G_t != G_(t+1) while UI_t = UI_(t+1).

SOURCE FORMALISM:
[OUR FORMALIZATION]

OUR FORMALIZATION:
Language-game identity is provisional and can be discovered through response and repair.

TENSION:
Games may overlap rather than switch cleanly.

MISSING:
Annotation protocol for multi-label game drift across long human-AI sessions.

BOUNDARY:
The twelve-game switchyard is an analytic model, not a natural taxonomy.

CITATION TRAIL:
interface category -> heterogeneous games -> session drift -> track change.

TEST:
Annotate turn-level executor, state, and success criteria; identify transitions and inter-rater agreement.

PLATFORM:
Language games; conversation; prompt drift
