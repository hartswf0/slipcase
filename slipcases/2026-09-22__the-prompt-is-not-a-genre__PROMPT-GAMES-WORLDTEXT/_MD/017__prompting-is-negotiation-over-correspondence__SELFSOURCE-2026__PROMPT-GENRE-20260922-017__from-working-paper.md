TITLE:
Prompting is negotiation over correspondence

SOURCE:
Watson Hartsoe, The Prompt Is Not a Genre: Language Games, Operative Ekphrasis, and Worldtext, Working Paper, 22 September 2026.

SOURCE URL:
https://github.com/hartswf0/slipcase/blob/main/slipcases/2026-09-22__the-prompt-is-not-a-genre__PROMPT-GAMES-WORLDTEXT/the-prompt-is-not-a-genre__2026-09-22.pdf

PASSAGE:
[OUR SYNTHESIS]\nAcross commands, scores, edits, models, and world-building, the common structure is not command or conversation but an iterative negotiation over which relations the continuation must preserve.

RESEARCH OBJECT:
[OUR INFERENCE]\nPROMPTING = NEGOTIATION OVER CORRESPONDENCE.

LOCAL MOVE:
Provide the paper's strongest common denominator without erasing differences among games.

SOURCE TERMS:
negotiation; correspondence; continuation; adequacy; repair

WHAT BECAME STRANGE:
The executor can contribute interpretation, the user can constrain without total control, and the world can resist both.

QUESTION:
Which party owns which decision, and which relations are negotiable versus invariant?

DEEPER QUESTION:
Can prompt failures be redescribed as ownership conflicts over decisions rather than as model misunderstanding?

MECHANISM:
A user offers an operative description; an executor continues it under a game; evidence exposes mismatch; later moves renegotiate adequacy.

FORMAL SHIFT:
D -> EXECUTE_G -> EVIDENCE -> NEGOTIATE -> D'.

SOURCE FORMALISM:
[OUR FORMALIZATION]

OUR FORMALIZATION:
Correspondence is selective and revisable rather than a naive one-to-one copy relation.

TENSION:
Not every creative use needs predeclared correspondence; some prompting is exploratory probe or play.

MISSING:
Empirical typology of negotiation patterns across deterministic and score-like systems.

BOUNDARY:
This is the working paper's synthesis, not a quoted source claim.

CITATION TRAIL:
five-part diagnostic + score + Operation Describe + worldtext -> negotiation over correspondence.

TEST:
Log explicit and implicit invariant negotiations across repair turns; compare with final acceptance criteria.

PLATFORM:
Prompt theory; correspondence; negotiation
