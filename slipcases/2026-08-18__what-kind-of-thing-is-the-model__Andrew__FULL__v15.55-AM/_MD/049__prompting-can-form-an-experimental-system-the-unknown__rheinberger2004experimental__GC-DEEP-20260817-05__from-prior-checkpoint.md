TITLE:
PROMPTING CAN FORM AN EXPERIMENTAL SYSTEM — the unknown object and the technical conditions for probing it develop together.

SOURCE:
Hans-Jörg Rheinberger — “Experimental Systems” — The Virtual Laboratory, Max Planck Institute for the History of Science, 2004; and MPIWG project “Generating Experimental Knowledge: Experimental Systems, Concept Formation and the Pivotal Role of Error.” SOURCE URL: https://vlp.mpiwg-berlin.mpg.de/essays/data/enc19?p=4 ; https://www.mpiwg-berlin.mpg.de/research/projects/GeneratingExperimentalKnowledge

PASSAGE:
[QUOTE]
“embodies in an experimentally manipulable manner what one does not yet exactly know.”

[PARAPHRASE]
Rheinberger distinguishes underdetermined epistemic things from more stabilized technical objects within experimental systems, while MPIWG’s later project description emphasizes explorative experimentation, concept revision, and the epistemic role of error.

RESEARCH OBJECT:
PROMPT-PRACTICE-AS-EXPERIMENTAL-SYSTEM.

LOCAL MOVE:
[[MJ-GC-010]] and [[MJ-GC-011]] show users arguing about what counts as evidence, whether prompt carryover exists, how seeds behave, and whether “magic” modifiers really cause effects. Read with Rheinberger, this looks less like a defective laboratory than an emergent experimental system whose object—the behavior of the generator—is still underdetermined while its probing techniques are themselves being invented.

SOURCE TERMS:
“experimental systems”
“epistemic things”
“technical objects”
“explorative” experimentation
“error”
“concept formation”

WHAT BECAME STRANGE:
The model is not the only uncertain object. The test procedure, the vocabulary of effects, the seed assumptions, and the criteria for failure are also being stabilized during use.

QUESTION:
What are the technical objects of prompt experimentation: seed, repeated batch, shared prompt, named benchmark character, comparison grid, version number?

DEEPER QUESTION:
Can a community produce robust knowledge about a proprietary stochastic model without full mechanistic access if it stabilizes enough experimental technique?

MECHANISM:
UNDERDETERMINED MODEL BEHAVIOR
↔ evolving technical probes
→ recurrent phenomena
→ naming / comparison / error detection
→ revised concepts and probes.

FORMAL SHIFT:
FROM: user tests a fixed black box.
TO: experimental object and practical test apparatus co-develop.

SOURCE FORMALISM:
Rheinberger distinguishes epistemic things—research objects whose properties are not yet fully known—from technical objects that stabilize and bound experimentation. The MPIWG project also distinguishes explorative experiments from simple theory tests.

TENSION:
Prompt communities lack many controls and institutional norms of scientific laboratories. The comparison is useful for mechanism of inquiry, not a claim that prompting is science in the full disciplinary sense.

MISSING:

BOUNDARY:
