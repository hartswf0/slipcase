ID:
THEORY-1994-KIRSH-MAGLIO

TITLE:
An action can be performed to uncover information rather than directly achieve the final goal

SOURCE:
David Kirsh and Paul Maglio, "On Distinguishing Epistemic from Pragmatic Action," Cognitive Science 18(4), 1994.

SOURCE URL:
https://doi.org/10.1207/s15516709cog1804_1

PASSAGE:
[QUOTE]
"actions performed to uncover information that is hidden or hard to compute mentally."

RESEARCH OBJECT:
[PARAPHRASE]
GENERATION CAN BE ANALYZED BY FUNCTION: PRODUCING AN ARTIFACT OR ACQUIRING INFORMATION.

LOCAL MOVE:
Follow [[MARTINA-2022-003]] and [[MARTINA-2022-021]] where a generated candidate changes what the practitioner can know or decide.

SOURCE TERMS:
"epistemic action"; "pragmatic action"; "uncover information"

WHAT BECAME STRANGE:
A generation that is a bad artifact can still be a successful cognitive probe.

QUESTION:
How many generative actions are requests for deliverables and how many are experiments performed to learn the next constraint?

DEEPER QUESTION:
Does cheap generation create a new class of epistemic action in which language perturbs a learned representational system?

MECHANISM:
Action changes the external state so that hidden or expensive information becomes easier to obtain.

FORMAL SHIFT:
UNCERTAINTY -> ACTION/PROBE -> PERCEPTIBLE RESULT -> INFORMATION GAIN.

SOURCE FORMALISM:
[PARAPHRASE]
Kirsh and Maglio distinguish pragmatic actions that advance a physical goal from epistemic actions that simplify cognition or reveal information.

OUR FORMALIZATION:
[OUR FORMALIZATION — NOT SOURCE SYNTAX]
If final-artifact utility is low but information gain is high, generation can be epistemically successful.

TENSION:
One action may be both pragmatic and epistemic.

MISSING:
User intent for each generation and post-generation information gain.

BOUNDARY:
The original experiments concern Tetris, not generative images.

CITATION TRAIL:
[[MARTINA-2022-003]] -> Kirsh & Maglio 1994 -> generation as probe -> separate output quality from inquiry value.

TEST:
Before each generation ask what function it is intended to serve; afterward record what information was gained and whether the result was retained.

PLATFORM:
Cognitive science; epistemic action
