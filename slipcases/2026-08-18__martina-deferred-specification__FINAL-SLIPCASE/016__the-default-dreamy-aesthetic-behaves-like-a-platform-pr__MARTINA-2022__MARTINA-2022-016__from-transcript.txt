RESEARCH OBJECT:
[OUR INFERENCE]
A COMMON AESTHETIC CAN EMERGE WHEN USERS DO NOT OVERRIDE MODEL REGULARITIES.

LOCAL MOVE:
Martina reports a recurring "dreamy" default in her own work and says other artists and the community tab show the same common theme.

SOURCE TERMS:
"dreamy"; "default"; "common theme"; "quite similar"

WHAT BECAME STRANGE:
A model can make stylistic coherence appear across unrelated users and prompts, creating a platform aesthetic that nobody individually specified.

QUESTION:
When does a model default become a collective style?

DEEPER QUESTION:
How can we distinguish platform aesthetic from shared prompt culture, training-data regularity, and user selection bias?

MECHANISM:
Underspecified style variables are repeatedly resolved within a concentrated visual region; public circulation then reinforces that region through imitation and selection.

FORMAL SHIFT:
MODEL REGULARITY <-> COMMUNITY SELECTION can form a feedback loop.

SOURCE FORMALISM:
[PARAPHRASE]
Martina describes a recurring default dreamy style across her own and others' work.

OUR FORMALIZATION:
[OUR FORMALIZATION — NOT SOURCE SYNTAX]
Observed platform style = model prior + prompt conventions + selection + visibility.

TENSION:
The source cannot isolate these causal components.

MISSING:
Historical prompt/output corpus across model versions.

BOUNDARY:
No claim that Midjourney had one technically fixed style parameter.

TEST:
Collect temporally stratified public outputs and prompts; model stylistic clustering while controlling for prompt tokens and model version.
