THEORY-1976-GOODMAN

TITLE:
Executability does not make a natural-language description a determinate score

SOURCE:
Nelson Goodman, Languages of Art: An Approach to a Theory of Symbols, Hackett, 1976.

SOURCE URL:
https://www.si.edu/object/siris_sil_1088421

PASSAGE:
[PARAPHRASE]
Goodman distinguishes score, sketch, and script within a theory of notation and compliance; not every descriptive instruction functions as a notation with determinate compliant instances.

RESEARCH OBJECT:
[OUR INFERENCE]
A PROMPT CAN BE COMPUTATIONALLY ACTIONABLE WHILE SEMANTICALLY UNDERDETERMINED.

LOCAL MOVE:
Pressure [[MARTINA-2022-009]]: prompt text can feel authored and executable without uniquely determining what counts as correct realization.

SOURCE TERMS:
"score"; "sketch"; "script"; "compliance"; "notation"

WHAT BECAME STRANGE:
Execution and determinacy are different properties.

QUESTION:
What kind of symbolic object is a prompt when many incompatible outputs can all plausibly satisfy it?

DEEPER QUESTION:
Which components of modern prompting are script-like, score-like, schema-like, or something else?

MECHANISM:
Notational systems impose stronger conditions on symbol differentiation and compliance than ordinary descriptive scripts.

FORMAL SHIFT:
EXECUTABLE(P) does not imply DETERMINATE_COMPLIANCE(P).

SOURCE FORMALISM:
[PARAPHRASE]
Goodman's book explicitly separates score, sketch, and script and develops formal requirements for notation.

OUR FORMALIZATION:
[OUR FORMALIZATION — NOT SOURCE SYNTAX]
Prompt clauses can range from binary constraint to graded description to open script.

TENSION:
Current schemas and runtime constraints can add score-like determinacy to some components of a larger prompt system.

MISSING:
Clause-level classification of prompt requirements and compliance judgments.

BOUNDARY:
Goodman is not writing about computation or LLMs.

CITATION TRAIL:
[[MARTINA-2022-009]] -> Goodman -> prompt as underdetermined instruction -> current schemas relocate some constraints.

TEST:
Classify real prompt clauses as binary, bounded, graded, open, reference, or procedural; test inter-rater agreement on compliance.

PLATFORM:
Aesthetics; notation; prompting
