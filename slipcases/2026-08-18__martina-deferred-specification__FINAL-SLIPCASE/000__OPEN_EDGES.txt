OPEN EDGES — MARTINA FIELD

1. RECOGNITION VS FORMATION
Can a generated feature create the internal image that later makes the output feel faithful?
TEST: pre-register visual/relational expectations; compare delayed intention reports for drift toward generated features.

2. SIX KINDS OF THE UNSAID
Distinguish omitted, tacit, unnoticed, undecided, delegated, and genuinely indeterminate properties.
TEST: require pre-generation classification before the model resolves the variable.

3. CONTROL VALUE VS DISCOVERY VALUE
When does specificity improve execution while reducing epistemic usefulness?
TEST: phase-sensitive prompting experiment across low/medium/high specificity.

4. TEMPLATE AS CURRICULUM
Does repeated prompt-template use change ordinary descriptive attention outside AI use?
TEST: blind scene-description task with expert prompt-template users and controls.

5. PLATFORM AESTHETIC
Does underspecification invoke a concentrated model default or preserve openness?
TEST: cross-user, cross-version visual clustering with prompt controls.

6. DECISION PROVENANCE
Where did each consequential feature become fixed: explicit prompt, template reminder, model proposal, user retention, community phrase, or post-edit?
TEST: reconstruct one final artifact feature-by-feature across the full trajectory.

7. ABUNDANCE AND JUDGMENT
Does cheaper candidate production move the bottleneck from making to discrimination?
TEST: fixed-time projects with different candidate-generation costs.

8. DIRECTION WITHOUT BLUEPRINT
What remains continuous enough for a changing artifact to remain answerable to the same project?
TEST: compare generative, sketch, prototype, and human-delegation trajectories.

9. ORDINARY DESIGN OPPOSITION
Suchman and Schön make purposive action under underdetermination older than generative AI. What, if anything, is new?
TEST: measure amount and provenance of consequential content introduced by execution across matched practices.

10. MIGRATION INTO INFRASTRUCTURE
Which distinctions discovered through practice later become templates, schemas, validators, permissions, or runtime gates?
TEST: version-controlled production systems linking each invariant to the failure or decision that caused formalization.
