CURRENT WAGER
The prompt is disappearing as a standalone object. Task-level language can shrink because durable specification migrates into repositories, skills, tools, tests, runtime state, benchmarks, reversible artifacts, and histories. Human language increasingly supplies intent, critique, permission, and objective; agents fill procedural gaps; artifacts return evidence that changes the next instruction.
