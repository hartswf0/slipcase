TITLE:
A prompt may specify a region of acceptable outcomes rather than a path to one output.

SOURCE:
Unattributed working manuscript — “Aphoristic Fragments,” fragments 29–32 — date not stated. fileciteturn0file0L372-L418

PASSAGE:
[QUOTE]
“I wanted to distinguish class from path.
A path says: go here, then here.
A class says: anything like this will do.”

[QUOTE]
“Perhaps a prompt does not write the object.
It writes the neighborhood in which the object may be found.”

RESEARCH OBJECT:
Constraint of an outcome region rather than specification of an execution trajectory.

LOCAL MOVE:
The manuscript tests a distinction between prompts that prescribe procedures and prompts that characterize acceptable families of outcomes, then immediately notes that this distinction predates machines.

WHAT BECAME STRANGE:
Prompting may differ from explicit procedural instruction in degree, while the class/path distinction itself belongs to writing more generally.

QUESTION:
When does a prompt constrain an output class, and when does it constrain the process by which an output is produced?

DEEPER QUESTION:
Can prompt forms be classified by which dimensions of a generative process they constrain—outcome, trajectory, relation, evaluation, or environment?

MECHANISM:
The operator supplies predicates or examples that define acceptable regions. The generative system searches or samples within those regions without following a fully specified path.

TENSION:
The manuscript itself notes that sonnets, genres, briefs, and ordinary writing already mix class and path constraints. The distinction cannot by itself define prompting.

MISSING:
Cases that isolate class constraints from path constraints strongly enough to test the distinction empirically.

BOUNDARY:
The “neighborhood” is explicitly treated as an attractive metaphor that requires suspicion, not as an established theory.

CITATION TRAIL:
Constraint programming; programming by example; search spaces; generative design; procedural specification; genre conventions.

TEST:
Construct prompts that hold output criteria constant while varying whether intermediate operations are specified. Measure output diversity and process sensitivity.
