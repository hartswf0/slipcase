ID:
PF-OPERATION-001

TITLE:
Description does not become operation; an apparatus makes description consequential.

SOURCE:
Unattributed working manuscript — “Aphoristic Fragments,” fragment 6 — date not stated. fileciteturn0file0L112-L124

PASSAGE:
[QUOTE]
“I keep wanting to say that description has become operation.
But this is already too smooth.
A description does not become an operation.
Someone builds a machine in which describing has effects.
The machine disappears from the sentence.”

RESEARCH OBJECT:
The hidden apparatus between linguistic description and operational consequence.

LOCAL MOVE:
The manuscript retracts its own strongest slogan. It relocates causal force from the sentence to an engineered arrangement in which sentences have effects.

SOURCE TERMS:
description
operation
machine
effects
disappearance

WHAT BECAME STRANGE:
“Description becomes operation” may attribute to language a transformation actually performed by infrastructure.

QUESTION:
What has to be built around a description before describing can reliably produce consequences?

DEEPER QUESTION:
When an interface makes the mediating apparatus disappear, does language appear to possess powers that actually belong to the language-apparatus coupling?

MECHANISM:
A linguistic input enters a constructed system; the system interprets that input and produces effects; repeated use makes the mediation phenomenologically unobtrusive; causal agency is then redescribed as a property of the words.

FORMAL SHIFT:
<description>
→ <machine-readable/contextualized input>
→ [system interprets and acts]
→ <consequence attributed to description>

SOURCE FORMALISM:
NONE

OUR FORMALIZATION:
[OUR FORMALIZATION — NOT SOURCE SYNTAX]
DESCRIPTION + APPARATUS + INTERPRETIVE PROCEDURE → EFFECT

TENSION:
The manuscript elsewhere remains attracted to formulations in which words themselves appear to act. This fragment refuses that compression.

MISSING:
The manuscript does not yet specify what component of “the machine” maps linguistic material onto effects: model, interface, parser, inference procedure, surrounding state, user selection, or some combination.

BOUNDARY:
The passage does not establish that language itself has become executable, nor that all descriptions within such systems produce operations.

CITATION TRAIL:
Speech-act theory; programming-language operational semantics; human-computer interaction work on direct manipulation and invisible infrastructure; studies of performativity that distinguish utterance from felicity conditions.

TEST:
Take one identical descriptive sentence and submit it unchanged to several differently configured systems. Inventory which surrounding components must change before the sentence produces different operations.
