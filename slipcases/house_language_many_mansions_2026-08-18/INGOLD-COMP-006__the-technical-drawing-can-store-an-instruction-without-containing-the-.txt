INGOLD-COMP-006

TITLE:
THE TECHNICAL DRAWING CAN STORE AN INSTRUCTION WITHOUT CONTAINING THE MOVEMENT REQUIRED TO EXECUTE IT.

SOURCE:
Tim Ingold — Making: Anthropology, Archaeology, Art and Architecture — 2013 — Chapter 9, “Drawing the Line,” p. 126.

PASSAGE:
[PARAPHRASE]
Ingold distinguishes gestural drawing from drawings whose primary purpose is specification. Technical drawings can encode directions for action, but bodily movement required for realizing those directions is absent from the marks themselves.

RESEARCH OBJECT:
INSTRUCTION IS NOT MOTION.

LOCAL MOVE:
Ingold separates TRACE OF AN ACT from PROPOSITION ABOUT AN ACT. Technical drawing specifies what should be made or how to proceed; actual movement must be supplied elsewhere.

SOURCE TERMS:
gesture; specification; proposition; technical drawing; instructions; movement; sketch; haptic; optical

WHAT BECAME STRANGE:
This is almost exactly the unresolved arrow in CODE → MATTER. A representation can encode motion without moving; something must reanimate the inscription.

QUESTION:
What is the last representation before movement?

DEEPER QUESTION:
Does machine execution eliminate interpretation—or replace embodied interpretation with a formally engineered mechanism for converting propositions into motion?

MECHANISM:
Representation specifies relations/operations; practitioner or machine reads according to conventions; reader supplies physical movement; movement changes matter.

FORMAL SHIFT:
<SPECIFICATION>
→ <INSTRUCTION-BEARING INSCRIPTION>
→ [REANIMATE AS MOVEMENT]
→ <PHYSICAL OPERATION>

SOURCE FORMALISM:
Ingold distinguishes GESTURAL LINES from NON-GESTURAL / SPECIFICATORY LINES; technical drawings lie toward the propositional/specifying side.

OUR FORMALIZATION:
[OUR FORMALIZATION — NOT SOURCE SYNTAX]
PROMPT → CAD → TOOLPATH → CONTROL SIGNAL → ACTUATOR MOTION → MATERIAL CHANGE. At each state ask: DOES THIS REPRESENT MOVEMENT OR IS THIS MOVEMENT?

TENSION:
[[HOUSE-COMP-006]] makes APT important because statements have defined machining consequences; Ingold forces a distinction between defined consequence and machining motion.

MISSING:
A precise account of symbolic instruction → electrical control → motor torque → tool displacement → force at material interface.

BOUNDARY:
Ingold is discussing drawing, not numerical control or programming-language semantics; extension is OUR inference.

CITATION TRAIL:
[[HOUSE-COMP-006]] → Ingold → Patrick Maynard → CAD/CAM → APT → G-code → machine controllers → actuator theory → robotics.

TEST:
Walk backward from a robot/CNC tool touching material and classify the last five states as INSCRIPTION, REPRESENTATION, SIGNAL, MOTION, FORCE; locate the exact transition.
