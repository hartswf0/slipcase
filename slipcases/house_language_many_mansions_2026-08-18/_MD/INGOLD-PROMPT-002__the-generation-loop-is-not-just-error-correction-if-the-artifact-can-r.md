ZETTEL

ID:
INGOLD-PROMPT-002

TITLE:
THE GENERATION LOOP IS NOT JUST ERROR CORRECTION IF THE ARTIFACT CAN REVEAL A FORM THAT WAS NEVER PRESENT IN THE INITIAL INTENTION.

SOURCE:
Tim Ingold — Making: Anthropology, Archaeology, Art and Architecture — 2013 — Chapter 9, “Drawing the Line,” pp. 126–127.

PASSAGE:
[QUOTE]
“The drawing’s meaning, if such a thing exists, is not in my control.”

[PARAPHRASE]
Ingold invokes Richard Talbot’s drawing practice to oppose the idea that making projects an already completed mental image onto a surface. Talbot compares drawing to cathedral construction whose form develops through intention, pragmatism, accident and ongoing work.

RESEARCH OBJECT:
ARTIFACT AS DISCOVERY ENVIRONMENT.

LOCAL MOVE:
Ingold attacks MENTAL IMAGE → INSCRIPTION. The drawing is produced through unfolding activity whose meaning and form need not be fully controlled in advance. This creates a distinction inside “THE ARTIFACT BECOMES SPECIFICATION.”

SOURCE TERMS:
drawing; pre-conceived image; hunch; meaning; control; intention; pragmatism; accident; carrying on

WHAT BECAME STRANGE:
The paper says UNDERDEFINED INSTRUCTION → ARTIFACT → MISSING CONSTRAINT BECOMES VISIBLE. Ingold opens UNDERDEFINED INSTRUCTION → ARTIFACT → UNANTICIPATED POSSIBILITY BECOMES VISIBLE. One produces correction; the other invention.

QUESTION:
When a generated artifact changes the next prompt, how do we tell whether it has exposed an ERROR or created a POSSIBILITY?

DEEPER QUESTION:
Could the distinctive unit of natural-language programming be not merely a specification loop but a joint specification–invention loop?

MECHANISM:
An initial orientation starts an inscription; developing artifact presents qualities not fully determined; those qualities alter judgement; maker follows, redirects, accepts, or rejects what emerges.

FORMAL SHIFT:
<ARTIFACT AS REALIZATION OF PRIOR INTENTION>
→ <ARTIFACT AS DEVELOPING TRACE>
→ [INSPECT / FOLLOW / REDIRECT]
→ <INTENTION MODIFIED BY ITS OWN MATERIALIZATION>

SOURCE FORMALISM:
NONE

OUR FORMALIZATION:
[OUR FORMALIZATION — NOT SOURCE SYNTAX]
PROMPT₀ → ARTIFACT₀ → FAILURE₀ → CONSTRAINT₁. Add: PROMPT₀ → ARTIFACT₀ → SURPRISE₀ → POSSIBILITY₁ → INTENTION₁. Therefore ARTIFACT FEEDBACK = ERROR DISCOVERY ∪ POSSIBILITY DISCOVERY.

TENSION:
If every unexpected output is coded as failure, the loop becomes increasingly conservative; a genealogy of constraints may erase the genealogy of discoveries that changed what the user wanted.

MISSING:
A vocabulary for positive surprises: UNEXPECTED PROPERTY WORTH KEEPING; NEW POSSIBILITY CREATED BY OUTPUT; GOAL CHANGED BECAUSE OF ARTIFACT.

BOUNDARY:
Ingold does not propose a theory of generative AI or claim computational artifacts possess independent creativity; mapping to generated artifacts is [OUR INFERENCE].

CITATION TRAIL:
[[THE PROMPT IS NOT THE PROGRAM]] → Ingold — “Drawing the Line” → Richard Talbot → Donald Schön — back-talk → generative design → mixed-initiative systems.

TEST:
Collect twenty prompt revisions and code whether SOMETHING WAS WRONG or SOMETHING INTERESTING APPEARED; separate FAILURE-DRIVEN from SURPRISE-DRIVEN revision.
