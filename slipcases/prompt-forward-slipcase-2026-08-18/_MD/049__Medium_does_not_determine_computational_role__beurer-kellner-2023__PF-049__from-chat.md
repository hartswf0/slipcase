ID: PF-049

TITLE:
Medium does not determine computational role.

SOURCE:
Beurer-Kellner, Fischer, and Vechev — Prompting Is Programming — 2023.

PASSAGE:
[PARAPHRASE] LMQL combines natural-language fragments with programming constructs to create executable language-model queries.

RESEARCH OBJECT:
Two artifacts made of words can occupy radically different operational positions.

LOCAL MOVE:
The source dissolves material-medium classification: prose can be embedded directly in an executable program.

SOURCE TERMS:
prompting; programming; query language; constraints.

WHAT BECAME STRANGE:
“Both are text” becomes as weak a classifier as “both are graphite.”

QUESTION:
What feature should classify prompt artifacts: syntax, execution, role, causal effect, or reuse?

DEEPER QUESTION:
Can scholarly ontology follow affordance rather than material form?

MECHANISM:
<text>
→ <execution context>
→ [interpret as instruction/program]
→ <operation>

FORMAL SHIFT:
NONE

SOURCE FORMALISM:
LMQL language.

OUR FORMALIZATION:
[OUR FORMALIZATION — NOT SOURCE SYNTAX]
ARTIFACT CLASS = USE + EXECUTION CONTEXT.

TENSION:
The same text can cross contexts without changing characters.

MISSING:
A contextual identity model for prompts.

BOUNDARY:
LMQL does not imply all natural language is program text.

CITATION TRAIL:
Wittgenstein/use; speech acts; programming-language semantics.

TEST:
Hold text constant while changing execution context and document which properties of the artifact change institutionally and computationally.
