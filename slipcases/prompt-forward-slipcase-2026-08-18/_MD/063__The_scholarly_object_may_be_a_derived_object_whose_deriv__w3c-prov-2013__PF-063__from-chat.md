ZETTEL

ID: PF-063

TITLE:
The scholarly object may be a derived object whose derivation itself needs provenance.

SOURCE:
Moreau and Missier, eds. — PROV-DM — 2013.

PASSAGE:
[PARAPHRASE] PROV represents derivation among entities through activities and agents.

RESEARCH OBJECT:
A “battle-tested prompt,” selection protocol, or loop can be treated as an entity derived from a larger interaction history.

LOCAL MOVE:
The model lets the quarry/stone metaphor become an explicit derivation relation.

SOURCE TERMS:
entity; derivation; activity; agent.

WHAT BECAME STRANGE:
A refined prompt can be both an output of research and an input to subsequent research.

QUESTION:
When should a prompt be modeled as data, method, result, or all three at different stages?

DEEPER QUESTION:
Can the same artifact legitimately change epistemic type over its lifecycle?

MECHANISM:
<interaction history>
→ [refinement activity]
→ <prompt artifact>
→ [experimental use]
→ <result>

FORMAL SHIFT:
NONE

SOURCE FORMALISM:
PROV derivation.

OUR FORMALIZATION:
[OUR FORMALIZATION — NOT SOURCE SYNTAX]
PROMPT lifecycle: RESULT₁ → METHOD₂.

TENSION:
Static scholarly categories may be mismatched to recursive artifact lifecycles.

MISSING:
Lifecycle-aware classification.

BOUNDARY:
PROV tracks derivation but does not assign epistemic type.

CITATION TRAIL:
Research software as both method and output; data-product lifecycles.

TEST:
Trace one prompt from exploratory conversation through stabilization, testing, publication, and reuse.
