ID: PF-054

TITLE:
System-component ablation and researcher-contribution attribution must not be conflated.

SOURCE:
Park et al. — Generative Agents — 2023.

PASSAGE:
[PARAPHRASE] The authors use ablations to demonstrate that reflection, planning, and memory components contribute to agent performance.

RESEARCH OBJECT:
Ablation attributes behavior to architecture, not architecture to a particular researcher.

LOCAL MOVE:
The method answers “what makes the system work?”

SOURCE TERMS:
ablation; architecture; planning; reflection; memory.

WHAT BECAME STRANGE:
“If removing my prompt destroys capability, my prompt is a contribution” skips from system causality to scholarly credit.

QUESTION:
What additional provenance links a load-bearing system component to an individual's intellectual contribution?

DEEPER QUESTION:
How should collaborative prompt systems distribute credit when many people iteratively shaped the component?

MECHANISM:
<component>
→ <system capability>
→ [ablation]
→ <causal dependence>
→ [? credit assignment ?]

FORMAL SHIFT:
NONE

SOURCE FORMALISM:
Component ablation.

OUR FORMALIZATION:
[OUR FORMALIZATION — NOT SOURCE SYNTAX]
ABLATION + CONTRIBUTION PROVENANCE → candidate scholarly credit.

TENSION:
A component can be causally critical because it is mundane infrastructure.

MISSING:
Novelty and contributor history.

BOUNDARY:
Ablation alone does not establish scholarly ownership.

CITATION TRAIL:
Version-control contribution; CRediT; invention attribution.

TEST:
Use Git histories and ablation together to separate component importance from contributor responsibility.
