# Contribution Topology

Derived map of content; immutable cards remain authoritative.

- [[PF-002]] Amount of interaction and amount of contribution are different variables.
- [[PF-011]] Output-only attribution loses upstream human information.
- [[PF-012]] Discarded model text can still leave a measurable writing-process contribution.
- [[PF-013]] The final text cannot distinguish workflows that leave the same surface artifact.
- [[PF-014]] “Upstream” contribution requires a graph, not merely a better percentage.
- [[PF-016]] Discarded intellectual work can be contribution without becoming authorship.
- [[PF-039]] Contribution quantity and contribution topology answer different questions.
- [[PF-040]] Token count is especially weak when informational leverage is concentrated.
- [[PF-044]] Recursive prompting converts attribution from a sentence problem into a workflow problem.
- [[PF-050]] Contribution thresholds should attach to roles before they attach to “AI use” globally.
- [[PF-054]] System-component ablation and researcher-contribution attribution must not be conflated.
- [[PF-058]] Capability claims are always indexed to a benchmark and system envelope.
- [[PF-073]] “Did AI write this?” can be replaced by a provenance query only if the provenance captures decision points.
- [[PF-075]] “Brainstorming” hides interaction structure that process datasets can recover.
- [[PF-076]] Human and AI contribution can be measured separately rather than treated as complements.
- [[PF-077]] More rigorous AI mediation can increase both human work and measured AI significance.
- [[PF-081]] Double ablation could separate output dependence from architecture dependence.
- [[PF-088]] Contributor vocabularies already demonstrate the power of verbs before verdicts.
- [[PF-089]] “AI use” is crude only if finer distinctions change an epistemic or institutional decision.
