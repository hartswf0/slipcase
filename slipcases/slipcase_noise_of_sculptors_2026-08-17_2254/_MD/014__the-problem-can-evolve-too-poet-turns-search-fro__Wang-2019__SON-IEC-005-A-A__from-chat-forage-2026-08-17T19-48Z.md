TITLE:
THE PROBLEM CAN EVOLVE TOO: POET turns search from finding answers into generating new questions that make new answers possible.

SOURCE:
Rui Wang, Joel Lehman, Jeff Clune & Kenneth O. Stanley — “Paired Open-Ended Trailblazer (POET): Endlessly Generating Increasingly Complex and Diverse Learning Environments and Their Solutions” — 2019.
SOURCE URL: https://arxiv.org/abs/1901.01753

PASSAGE:
[QUOTE]
“whether the problems themselves can be generated by the algorithm at the same time as they are being solved.”

[PARAPHRASE]
POET jointly generates environmental challenges and optimizes agents for them, while allowing solutions discovered for one environment to transfer into another.

RESEARCH OBJECT:
PROBLEM–SOLUTION COEVOLUTION.

[[SON-IEC-005-A]] made the objective suspicious because a fixed goal can conceal stepping stones.

POET makes a stranger move:

DO NOT ONLY CHANGE THE SEARCHER.

CHANGE WHAT COUNTS AS THE PROBLEM.

LOCAL MOVE:
The previous branch assumed a relatively stable environment of possibilities in which better search policies might avoid deceptive objectives.

POET removes that stability.

An agent and an environment become a pair.

The environment mutates.

The agent adapts.

New environments survive when they are neither trivial nor impossible.

Solutions can migrate between environments.

A solution developed for one problem can unexpectedly become the stepping stone for another problem.

WHAT BECAME STRANGE:
A problem no longer has to precede its solution.

The system can produce:

a partial solution
→ which makes a new problem worth asking
→ whose solution becomes useful somewhere else
→ which opens another problem
→ which retroactively makes the earlier partial solution significant.

The normal sequence:

QUESTION
→ SEARCH
→ ANSWER

breaks.

The question itself can be a product of search.

QUESTION:
What changes if generative prompting is allowed to evolve not only candidate outputs but the task, constraint, or question those outputs are supposed to satisfy?

DEEPER QUESTION:
Could creative discovery require a system in which ANSWERS invent QUESTIONS that could not have been formulated before those answers existed?

MECHANISM:
POET maintains paired:

ENVIRONMENT
+
AGENT

New environments are generated from existing environments.

Agents are optimized within environments.

Candidate environments must satisfy a minimal criterion of being solvable but not already trivial.

Periodically, agents are evaluated on environments other than their own.

A transferred agent can replace an environment’s incumbent when it performs better.

Thus useful competence can jump between problem lineages.

FORMAL SHIFT:
FROM:

FIXED PROBLEM P
→ search solutions S
→ best S

TO:

(P_t, S_t)
→ mutate P_t
→ adapt S_t
→ create (P_t+1, S_t+1)

PLUS:

S_i
→ transfer into P_j
→ unexpected improvement
→ new lineage

SOURCE FORMALISM:
[PARAPHRASE]

POET pairs generation of environmental challenges with optimization of solutions, explores multiple paths through problem–solution space, and allows stepping-stone solutions to transfer between problems.

OUR FORMALIZATION:
[OUR FORMALIZATION — NOT SOURCE SYNTAX]

Ordinary prompt search:

SEARCH(P)
→ O*

Coevolutionary prompt search:

(P_t, O_t)
→ MUTATE_PROBLEM(P_t)
→ MUTATE_SOLUTION(O_t)
→ (P_t+1, O_t+1)

TRANSFER:

O_i + P_j
→ O'_j

where:

VALUE(O_i)

may be invisible inside P_i

but become visible inside P_j.

TENSION:
This cuts against a central assumption in prompt engineering:

that the user must formulate the correct request before the model can produce the correct result.

POET suggests another possibility:

the inability to formulate the correct prompt may not be a user failure.

The correct problem may literally not exist yet.

But POET’s environments are explicitly represented computational objects.

A human creative brief is not automatically an evolvable environment.

MISSING:
A representation of creative PROBLEMS that can mutate without collapsing into arbitrary task drift.

A minimal criterion distinguishing:

productive reframing
from
changing the subject.

Evidence that transferring artifacts between evolving prompts produces breakthroughs unavailable through optimization of a fixed brief.

BOUNDARY:
POET establishes the computational possibility of coevolving problems and solutions in reinforcement-learning environments.

It does not establish that human creative practice or prompt craft follows this mechanism.

Similarity is not genealogy.

TEST:
Build three generative-search conditions with identical generation budgets.

A. FIXED PROMPT:
Only candidate outputs may vary.

B. MUTABLE PROMPT:
The prompt itself may mutate, but all branches retain the original success criterion.

C. COEVOLVING PROBLEM:
Both the prompt and its evaluation criterion may mutate, provided each descendant remains connected by explicit ancestry.

Permit outputs from one branch to be imported as seeds into another branch.

Record:

problem ancestry
artifact ancestry
cross-branch transfers
quality
novelty
whether final valued artifacts satisfy goals absent from the initial task

The critical case is:

FINAL VALUE
>
anything reachable under original evaluation

AND

the valued criterion itself emerged during search.
