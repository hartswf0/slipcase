TITLE:
INGOLD SPLITS LANGUAGE INTO TWO OPERATIVE MODES: SPECIFICATIONS DEFINE PROJECTS; STORIES ORIENT PRACTITIONERS THROUGH UNFINISHED SITUATIONS.

SOURCE:
Tim Ingold — Making: Anthropology, Archaeology, Art and Architecture — 2013 — Chapter 8, “Telling by Hand,” pp. 110–111.

PASSAGE:
[PARAPHRASE]
Ingold distinguishes complete specification from telling that directs attention. Specifications state materials, dimensions, and movements and establish a project; stories help practitioners perceive where to go and what to attend to while proceeding.

RESEARCH OBJECT:
LANGUAGE CAN GUIDE ACTION WITHOUT FULLY SPECIFYING IT.

LOCAL MOVE:
Ingold opposes SPECIFICATION, which attempts to state what is required, to STORY, which educates attention so a practitioner can continue intelligently.

SOURCE TERMS:
telling; specification; guidance; story; project; itinerary; attention; carry on; practice

WHAT BECAME STRANGE:
Perhaps a natural-language prompt succeeds not because ordinary language becomes sufficiently precise, but because the computational system supplies missing specificity downstream.

QUESTION:
Is a prompt a specification, or is it guidance for a machine that already knows how to continue?

DEEPER QUESTION:
If a generative model can act from underspecified language, where does missing information come from: training data, defaults, world model, inference, platform conventions, hidden software, user iteration?

MECHANISM:
One mode fixes attributes and operations; another points attention toward a course without exhausting particulars; competent action fills what has not been stated.

FORMAL SHIFT:
<LANGUAGE AS COMPLETE DESCRIPTION>
→ <LANGUAGE AS ORIENTATION>

→ <SITUATED ACTION>

SOURCE FORMALISM:
Ingold explicitly contrasts specification with storytelling and associates them with PROJECT and ITINERARY.

OUR FORMALIZATION:

SPECIFICATION MODEL: UTTERANCE → EXPLICIT PARAMETERS → EXECUTION. GUIDANCE MODEL: UTTERANCE → ORIENTATION → MODEL SUPPLIES UNSAID STRUCTURE → ACTION → OBSERVATION → CONTINUATION. PROMPT may be a pointer into learned possibilities.
