# THE PROMPT IS NOT THE PROGRAM

- [[INGOLD-PROMPT-001]] — DEFERRED FORMALIZATION HAS AN OLDER DESIGN LOGIC: DESIGN CAN ANTICIPATE WITHOUT PRE-SPECIFYING THE FINAL FORM.
- [[INGOLD-PROMPT-002]] — THE GENERATION LOOP IS NOT JUST ERROR CORRECTION IF THE ARTIFACT CAN REVEAL A FORM THAT WAS NEVER PRESENT IN THE INITIAL INTENTION.
- [[INGOLD-PROMPT-003]] — A PROMPT MAY WORK NOT BY SPECIFYING THE RESULT BUT BY GIVING A CAPABLE SYSTEM ENOUGH GUIDANCE TO CONTINUE.
- [[INGOLD-PROMPT-004]] — INGOLD’S “EVERY TECHNICAL GESTURE IS A QUESTION” MAKES EXECUTION ITSELF A SPECIFICATION-PRODUCING ACT.
- [[INGOLD-PROMPT-005]] — THE LOOP BECOMES NECESSARY WHERE RULES CAN GUIDE ACTION BUT CANNOT PREORDAIN WHAT THE SITUATION WILL REQUIRE.
- [[INGOLD-PROMPT-006]] — A CONSTRAINT MAY BE BETTER UNDERSTOOD AS THE HISTORY OF WHAT HAPPENED UNDER TEST THAN AS A STATIC ATTRIBUTE OF THE DESIRED OUTPUT.
- [[INGOLD-PROMPT-007]] — THE ROOF PROBLEM IS NOT JUST THAT FAILURE MUST BE LEGIBLE; THE MATERIAL WORLD MUST BE ALLOWED TO INVALIDATE THE MODEL.
- [[INGOLD-PROMPT-008]] — “THE PROMPT IS NOT THE PROGRAM” BECOMES STRONGER IF PROGRAMMING IS LOCATED IN THE INTERLEAVING OF DESCRIPTION AND EXECUTION RATHER THAN IN EITHER ONE ALONE.
