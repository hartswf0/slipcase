“Between code and poetry” decomposes into semantic slack and consequence coupling.

PASSAGE:
[PARAPHRASE]
The source contrasts programming’s attempt to constrain interpretation with prompting’s use of controlled ambiguity, then gives a phrase about making a house “remember” that must be simultaneously evocative and operative.

RESEARCH OBJECT:
Two independent variables:

SEMANTIC SLACK:
how much consequential detail remains unresolved by the expression itself.

CONSEQUENCE COUPLING:
how directly interpretation of the expression can modify reachable states.

Prompting becomes especially interesting where both remain high.

LOCAL MOVE:
The source uses “between code and poetry” as a productive metaphor but also warns against treating code and poetry as territories with a clean border.

WHAT BECAME STRANGE:
A single continuum bundles together at least two properties.

Poetry can be highly interpretively open but weakly coupled to computational state transitions.

Formal code can be tightly consequence-coupled while minimizing semantic slack.

Prompting can permit substantial interpretive completion while still producing immediate computational consequences.

QUESTION:
Is the notable property of contemporary prompting the combination of high semantic slack and high consequence coupling?

DEEPER QUESTION:
What kinds of social or technical systems previously permitted high values on both dimensions, and what has changed in their scale or accessibility?

TENSION:
Code can have substantial semantic openness.
Natural-language contracts and commands can be both ambiguous and consequential.
Prompts can be extremely rigid.
Poetry can directly reorganize institutional or political action.

Therefore no quadrant uniquely defines any genre.

MISSING:
Semantic slack must be decomposed into:
- parameter omission,
- procedural omission,
- lexical ambiguity,
- contextual dependence,
- tolerance for variation,
- reliance on priors.

Consequence coupling must be decomposed into:
- immediacy,
- mediation,
- authority,
- reversibility,
- scale,
- state-space effect.

BOUNDARY:
The evidence licenses a research coordinate system, not a definition of prompting.

It does not establish historical novelty.
