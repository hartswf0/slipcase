ID:
PB-FORAGE-019

TITLE:
If capability is distributed, the Prompt Battle has lost the wrestler’s body.

SOURCE:
Roland Barthes — “The World of Wrestling” — Mythologies — Hill and Wang, 1972. Scan pp. 17–18. fileciteturn5file0L3-L4

PASSAGE:
[PARAPHRASE]

Barthes treats the wrestler’s physique as a basic sign that already contains the encounter before individual actions unfold. The body continuously produces readable signs through gesture, posture, expression, and type.

The spectacle therefore has a visible location from which meaning appears to emanate.

RESEARCH OBJECT:
[[PB-FORAGE-003]] and [[PB-FORAGE-010]] dissolved model capability into a coupled configuration:

model
operator
prompting policy
history
tools
system conditions
evaluation environment.

Barthes reveals what this gain in theoretical accuracy destroys.

The Prompt Battle no longer has a body.

There is no single visible entity whose gestures can be read as the location of capability.

LOCAL MOVE:
Do not restore the model as the fictional body.

BUILD AN EXPLICIT SYSTEM BODY.

SOURCE TERMS:
physique
body
basic sign
gesture
type
expression
spectacle

WHAT BECAME STRANGE:
The user sees one chat box.

The experiment may contain:

a foundation model
post-training
system instructions
moderation
retrieval
tools
hidden memory
sampling parameters
an expert operator
judge feedback.

The interface visually compresses this assemblage into one speaking character.

The apparent body of the model is therefore an attribution machine.

QUESTION:
What must be visible in the ring before observers can correctly attribute a capability or failure?

DEEPER QUESTION:
Can a distributed system become publicly intelligible without being falsely personified as one coherent agent?

MECHANISM:
The interface presents a unified conversational surface.

Observers attribute outcomes to the most visually salient apparent actor.

Hidden components remain causally active but semiotically absent.

Capability attribution therefore follows interface visibility rather than causal contribution.

SOURCE FORMALISM:
NONE

OUR FORMALIZATION:
[OUR FORMALIZATION — NOT SOURCE SYNTAX]

Let causal system be:

S = {M, O, P, H, T, G, J}

where:

M = model
O = operator
P = prompting policy
H = history
T = tools
G = system/governance conditions
J = judgment procedure.

Interface I currently maps:

I(S) → apparent actor A

where A is usually labeled with the model name.

The resulting attribution:

Outcome → A

can hide the causal structure of S.

TENSION:
The paper’s elicitation-ecology argument becomes more accurate by distributing capability.

It becomes dramatically weaker because no actor remains visible enough to fight.

WWE logic demands bodies.

Systems theory dissolves them.

The paper must solve this rather than choosing one side.

MISSING:
A representational form that can give a coupled system a visible “body” while preserving its internal causal plurality.

BOUNDARY:
Barthes’s analysis depends on human bodies performing visible signs.

Language models do not possess bodies in this sense.

Treating interface and system representation as a functional analogue is [OUR INFERENCE].

TEST:
Present the same Prompt Battle transcript to three groups.

A:
only model name + transcript.

B:
transcript + full component inventory.

C:
transcript + a turn-by-turn visual causal trace showing operator intervention, system constraint, tool invocation, context change, and model output.

Ask each group:

Where does the capability reside?
What caused the decisive reversal?
What would need to be removed to make the capability disappear?

If attribution changes substantially across displays, interface visibility is part of capability judgment.
