TITLE:
The paper needs a heel strong enough to beat the thesis.

SOURCE:
Roland Barthes — “The World of Wrestling” — Mythologies — Hill and Wang, 1972. Scan pp. 17–24. fileciteturn5file0L3-L7

PASSAGE:
[PARAPHRASE]

Barthes describes wrestlers as immediately legible types whose bodies, gestures, and repeated actions make a role progressively unmistakable. The villain is not merely an opponent with a different opinion. The role gathers a coherent set of expectations that the performance repeatedly fulfills, violates, and intensifies.

RESEARCH OBJECT:
The paper’s opposition currently appears mainly as methodological caution:

perhaps capability really should remain attributable to the model.

That is too weak.

A SmackDown paper needs an opponent capable of destroying the elicitation-ecology thesis.

The strongest heel is:

THE PORTABLE MODEL.

Its proposition:

If a capability cannot survive separation from a particular operator, history, tool configuration, prompt search, or evaluation apparatus, then calling it a capability of the AI system empties capability of useful meaning.

LOCAL MOVE:
Stop letting the counterargument appear as qualification.

Give it a body, doctrine, victories, and a finishing move.

WHAT BECAME STRANGE:
The distributed-capability thesis can assimilate almost any counterexample.

Operator mattered?
Include operator.

Tool mattered?
Include tool.

Benchmark mattered?
Include benchmark.

History mattered?
Include history.

A theory that expands the system boundary whenever challenged risks becoming impossible to defeat.

The heel reveals this immediately.

QUESTION:
What observation would force the elicitation-ecology thesis to contract its system boundary rather than expand again?

DEEPER QUESTION:
When does relational explanation become explanatory capture-all?

MECHANISM:
A distributed account explains performance by expanding the relevant causal system.

Every discovered dependency becomes another system component.

Unless an exclusion rule exists, explanatory scope grows monotonically.

The theory can become unfalsifiable through boundary expansion.

FORMAL SHIFT:
<OUTCOME>
→ discover dependency d_1
→ expand system S
→ discover dependency d_2
→ expand S
→ ...

WITHOUT STOPPING RULE:

S → EVERYTHING CAUSALLY RELEVANT.

SOURCE FORMALISM:
NONE

OUR FORMALIZATION:
[OUR FORMALIZATION — NOT SOURCE SYNTAX]

FACE:

CAPABILITY = property of elicitation ecology E.

HEEL:

A capability deserves attribution to system X only if it satisfies some portability criterion P across substitutions of external dependencies.

THE MATCH:

Does empirical competence remain under:

operator swap
history reset
prompt-family change
tool removal
interface change
judge change?

The result determines which dependencies are constitutive and which are merely enabling.

TENSION:
The model-essentialist position falsely hides interactional dependencies.

The ecology position risks dissolving the evaluated object completely.

Neither side can be allowed an easy victory.

MISSING:
A principled stopping rule for system-boundary expansion.

Possible candidates remain unresolved:

causal necessity
reliable coupling
portability
replaceability
control
design ownership
user availability.

BOUNDARY:
The “heel” structure is [OUR INFERENCE] from Barthes’s analysis of wrestling types.

It must not be mistaken for evidence that one theoretical position is morally villainous.

TEST:
Write the strongest possible PORTABLE MODEL position as a one-page argument.

Require it to specify three empirical results that would defeat the elicitation-ecology thesis.

Then require the ecology position to specify three empirical results that would defeat itself.

Any claim for which no possible result can count as a loss is removed from the paper or rewritten.
