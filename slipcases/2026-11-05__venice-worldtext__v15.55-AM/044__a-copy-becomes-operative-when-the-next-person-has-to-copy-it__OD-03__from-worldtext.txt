ZETTEL

ID: OD-03

TITLE: A copy becomes operative when the next person has to copy it

SOURCE: Sol LeWitt — Wall Drawing 797 — 1995 — score and installation account at MASS MoCA. Bolter and Hartsoe — Operative Ekphrasis: From Imagetext to Worldtext — §3.

PASSAGE: [QUOTE] The score directs drafters to copy “the last line drawn.” [PARAPHRASE] At MASS MoCA the head drafter first tested several lines on paper to see how they would evolve under copying.

RESEARCH OBJECT: The choice of which prior artifact becomes the next instruction’s referent.

LOCAL MOVE: LeWitt turns an instruction to copy into a chain in which each new line becomes the source for another drafter. The installation adds a rehearsal in which possible first lines are evaluated by running that chain.

SOURCE TERMS: copy, last line drawn, test lines, irregular horizontal line.

WHAT BECAME STRANGE: Choosing the first line is already a judgment about the future behavior of the whole procedure. Later drafters can faithfully copy their immediate predecessors while collectively moving far from the first line.

QUESTION: When a generated image comes back as feedback, what will the next operator take as authoritative: the original description, the last image, or a newly selected feature of that image?

MECHANISM: The previous mark supplies the local target. The next drafter interprets it under the score and draws another mark. That output becomes the next target. The visible chain retains evidence of changes that a workflow showing only the latest render would hide.

FORMAL SHIFT: <drawn line> → <visible reference for the next drafter> → [copy with a new hand and color] → <new line that becomes a reference>

SOURCE FORMALISM: A starting line, an ordered marker sequence, a non-touching condition for the first copy, repeated copying of the last line, and the wall’s bottom as the stopping boundary.

OUR FORMALIZATION: [OUR FORMALIZATION — NOT SOURCE SYNTAX] Use a single starting image of an irregular orb rim. In one chain, each round refers to the previous output. In a second, every round refers back to the starting image. In a third, the operator explicitly promotes one accidental mark to a requirement for subsequent rounds.

TENSION: Feedback can help diagnose a default, as Operation Describe argues. The same feedback path can also stabilize an unnoticed deviation. LeWitt makes cumulative variation part of the drawing, which makes it a useful counterexample to treating all drift as failure.

MISSING: A way to tell from the work trace which deviations were noticed and adopted, which were tolerated, and which passed unseen.

BOUNDARY: The score establishes a dependency between successive marks. It provides no evidence that diffusion or a human hand reproduces that dependency in the same way.

CITATION TRAIL: [[AP-05]] → Wall Drawing 797 → the head drafter’s test sheets → Operation Describe’s account of the image as a diagnostic return.

TEST: Run the three chains for five rounds using identical edit wording and compare contour displacement. Ask the operator at each round which feature they accepted as a new constraint. Check whether the output history alone would have revealed that decision.
