RESEARCH OBJECT:
The archive contains its own critique of prompt magic.

That matters.

“Magic” is not simply what naïve users call an incomprehensible model. It appears precisely where repeated executions make causality difficult to identify.

A user adds twelve words.
The output improves.
Which word mattered?

A user reruns the prompt.
The output improves again.
Did anything in the language matter?

A user preserves a seed.
The effect appears reproducible.
Was the seed causal in the hypothesized way, or did fixing randomness merely make another variable easier to observe?

The stronger object is therefore not:

PROMPT MAGIC

but:

CAUSAL ATTRIBUTION UNDER STOCHASTIC EXECUTION.

Superstition may be generated by the experimental conditions of the interface itself.

WHAT BECAME STRANGE:
A stochastic interface can manufacture ritual behavior in otherwise technically sophisticated users.

If one changes the prompt while the seed changes, then observes a better image, at least two variables moved simultaneously.

The interface permits causal stories faster than it permits causal discrimination.

QUESTION:
How much early “prompt lore” was produced by confounding semantic intervention with stochastic variation?

DEEPER QUESTION:
Does model opacity create superstition by itself, or does superstition emerge more specifically from an experimental interface that makes uncontrolled comparison extraordinarily easy?

MECHANISM:
[OUR INFERENCE]

prompt₁
+ random state₁
→ output₁

prompt₂
+ random state₂
→ output₂

User observes:

output₂ > output₁

and attributes:

difference = prompt₂ - prompt₁

although:

random state₂ ≠ random state₁.

Repeated informal use can therefore produce apparently stable causal explanations from uncontrolled experiments.

FORMAL SHIFT:
PROMPT
→ OUTPUT
→ BELIEF ABOUT LANGUAGE

PROMPT
+ SEED

+ DEFAULTS
+ SAMPLING VARIANCE
→ OUTPUT
→ HUMAN CAUSAL ATTRIBUTION
→ RETAINED OR DISCARDED PROMPT LORE

SOURCE FORMALISM:
[PARAPHRASE] Midjourney documents a seed as an initialization value for the random starting noise used in generation. A random value is selected when the user does not explicitly provide one.

OUR FORMALIZATION:
[OUR FORMALIZATION — NOT SOURCE SYNTAX]

Let:

p = prompt
s = seed
M = model/version
d = defaults
x = generated image

x = G(M,p,s,d)

The practitioner wants:

∂x / ∂p

but informal prompting frequently observes:

G(M,p₁,s₁,d) versus G(M,p₂,s₂,d)

where:

p₁ ≠ p₂
s₁ ≠ s₂

The experiment therefore cannot isolate the prompt effect.

“Magic” can be the folk theory produced by this identification failure.

TENSION:
The archive contains both positions simultaneously:

PROMPT MAGIC IS REAL:
certain words appear to produce repeatable desirable effects.

PROMPT MAGIC IS SUPERSTITION:
long prompts contain ignored or causally irrelevant material.

Neither reading can be accepted without controlling the execution conditions.

MISSING:
A historical corpus of early prompt claims paired with controlled retrospective ablation tests.

We do not know what percentage of famous 2022 prompt lore survived even elementary fixed-seed experiments.

BOUNDARY:
Fixing a seed does not make a generative system perfectly deterministic across every model, version, hardware path, or implementation.

The point is methodological: holding known variables stable allows stronger causal tests than uncontrolled reroll comparison.
