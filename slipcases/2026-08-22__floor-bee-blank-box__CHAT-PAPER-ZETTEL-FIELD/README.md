## Seed

> **What does the work think the participant did?**

Open-ended media can make the visible action boundary disappear while preserving an operative grammar behind the interface. The participant acts; the work treats the action as something; later conduct reveals that treatment. The research practice is deliberately low: **probe the edge, then follow what survives.**

## Why this GitHub copy is text-native

The connected GitHub write interface available in this chat exposes UTF-8 repository writes but not a binary file-upload action. This committed field therefore carries the complete research record in text-native form: the 90 zettels, raw/reconstructed chat archive, five manuscript states, source maps, and BibTeX. `_LINEAGE/BINARY_ARTIFACTS.md` records SHA-256 hashes for the companion binary master ZIP and rendered PDF/DOCX artifacts.

The downloadable master ZIP produced in the same chat preserves those rendered binaries, figures, and exact historical package ZIPs in addition to everything stored here.

## Rehydrating the Slipcase cards

Run `python REHYDRATE.py` from this directory to reconstruct the 90 canonical numbered root `.txt` cards from `_LINEAGE/ZETTELS.txt`. The script never overwrites existing files. Once rehydrated, the repository's normal `build_all.py` can ingest the field into the generated Slipcase viewers.

## Archive boundary
