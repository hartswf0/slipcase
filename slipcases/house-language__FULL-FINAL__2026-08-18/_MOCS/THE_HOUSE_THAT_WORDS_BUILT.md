# THE HOUSE THAT WORDS BUILT

- [[HOUSE-LANG-001]] — HEIDEGGER’S “HOUSE OF BEING” MAKES HUMANS GUARDIANS OF LANGUAGE, NOT BUILDERS THROUGH LANGUAGE.
- [[HOUSE-LANG-004]] — ALBERTI SPLITS BUILDING BETWEEN LINEAMENTS AND STRUCTURE: THE REPRESENTATION CAN PRESCRIBE FORM WITHOUT BEING THE BUILDING.
- [[HOUSE-LANG-005]] — AUSTIN MAKES WORDS OPERATIVE ONLY INSIDE FELICITOUS ARRANGEMENTS OF PEOPLE, PROCEDURES, CIRCUMSTANCES, AND OTHER ACTIONS.
- [[HOUSE-LANG-006]] — EVANS LOCATES ARCHITECTURAL POWER IN THE GAP BETWEEN REPRESENTATION AND BUILDING, NOT IN THEIR IDENTITY.
- [[HOUSE-COMP-000]] — THE HOUSE THAT WORDS BUILT IS NOT A CLAIM ABOUT MAGIC WORDS; IT IS A QUESTION ABOUT WHETHER THE CHAIN FROM SENTENCE TO MATTER CAN BE COMPUTATIONALLY CLOSED.
- [[HOUSE-COMP-001]] — SHRDLU MAKES AN ORDINARY ENGLISH SENTENCE CAUSALLY UPSTREAM OF A CHANGED WORLD-STATE.
- [[HOUSE-COMP-003]] — EASTMAN’S BUILDING DESCRIPTION SYSTEM MOVES THE BUILDING FROM A SET OF DRAWINGS INTO A COMPUTABLE DATA STRUCTURE.
- [[HOUSE-COMP-004]] — GLIDE MAKES “LANGUAGE FOR BUILDING” LITERAL BY DEFINING A PROGRAMMING ENVIRONMENT FOR REPRESENTING PHYSICAL SYSTEMS IN DESIGN-AND-CONSTRUCTION DETAIL.
- [[HOUSE-COMP-006]] — APT GIVES LANGUAGE STATEMENTS MACHINING SEMANTICS: PROGRAM TEXT CAN TERMINATE IN PHYSICAL TOOL MOTION.
- [[INGOLD-COMP-001]] — THE SENTENCE-TO-WALL PIPELINE BECOMES HYLOMORPHIC WHEN IT TREATS SOURCE DESCRIPTION AND FINISHED MATTER AS THE ONLY STATES THAT MATTER.
- [[INGOLD-COMP-006]] — THE TECHNICAL DRAWING CAN STORE AN INSTRUCTION WITHOUT CONTAINING THE MOVEMENT REQUIRED TO EXECUTE IT.
