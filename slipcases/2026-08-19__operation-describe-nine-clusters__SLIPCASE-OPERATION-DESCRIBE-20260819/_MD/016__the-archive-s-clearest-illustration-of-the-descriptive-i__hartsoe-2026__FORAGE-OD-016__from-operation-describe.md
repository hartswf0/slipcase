TITLE:
THE ARCHIVE'S CLEAREST ILLUSTRATION OF THE DESCRIPTIVE/INTERPRETIVE/OPERATIVE TRIAD CONTAINS NO DESCRIPTION

SOURCE:
Watson Hartsoe — PAPERS/attention-tax-semiotics.md §12 "The Descriptive / Interpretive / Operative Triad" — 2026; cross-read with PAPERS/ripples-perspectival-finitude.md §4.1 "The Spider's Umwelt"

PASSAGE:
[QUOTE]
§12:
"'The silk thread is vibrating.' Descriptive: Reports the physical state of a thread. Interpretive: Within the spider's Umwelt, this vibration signifies 'prey captured' rather than 'wind draft.' Operative: Mutates the spider's action-space from rest to attack."

RESEARCH OBJECT:
No sign vehicle exists in the spider case. The spider does not read the sentence. The vibration is a physical event, and the sentence is the analyst's.

The example therefore demonstrates stimulus→response, and labels it operative description. Applied consistently, every causally efficacious event in the world becomes an operative description.

LOCAL MOVE:
The triad is introduced to give operativity a layered structure. The spider is chosen because it makes the layers vivid and because Umwelt is already in the archive's vocabulary from the RIPPLES work.

Vividness is purchased by removing the only element that makes the concept bounded.

WHAT BECAME STRANGE:
The archive's single most important due-diligence question is "When is a description NOT operative?" (label-00, opening line: "If you cannot answer that, the concept becomes too broad and collapses into 'all language does stuff.'")

Its flagship example collapses the concept even further — into "all events do stuff." The illustration is the strongest existing argument *against* the framework, and it appears inside the framework's own exposition.

QUESTION:
What minimal property must a thing have to be a description rather than a stimulus?

DEEPER QUESTION:
Is the archive's real object not description at all but *salience architecture* — in which case the spider example is fine and the word "description" is the error?

MECHANISM:
Stimulus:
<PHYSICAL EVENT> → <SENSOR> → <STATE CHANGE> → <ACTION>
No token. Nothing detachable. Nothing re-applicable. Nothing contestable.

Description:
<DESCRIBER> → <DETACHABLE TOKEN> → <OPERATOR READS TOKEN> → <STATE CHANGE> → <ACTION>
The token can be copied, misapplied to a second object, quoted, disputed, and revoked.

The spider case has the first structure and is presented as the second.

FORMAL SHIFT:
<EVENT>
→ <NO REPRESENTATION>
→ [CAUSAL COUPLING]
→ <ACTION>

which is precisely the null case the triad was built to exclude.

SOURCE FORMALISM:
The archive supplies: Meaning = Description + Interpretive Frame + Operative Consequence. Nothing in this sum requires that the description be a token distinct from the state it reports.

OUR FORMALIZATION:
[OUR FORMALIZATION — NOT SOURCE SYNTAX]

Proposed necessary condition — **detachability**:

D is a description only if there exist at least two distinct objects o₁, o₂ such that D can be applied to either, and application is revocable.

Test the archive's cases:
  "toxic"           applies to any comment; revocable  → description ✓
  "good first issue" applies to any issue; revocable   → description ✓
  tool description   applies to any function; editable → description ✓
  thread vibration   applies to nothing else; not revocable → stimulus ✗

Detachability also explains why misrouting is possible only for descriptions: a token that can be applied can be *mis*applied. A stimulus cannot be wrong.

The archive's entire error chapter (label-01 §8: "Error is where the system becomes visible") presupposes detachability without naming it.

TENSION:
READING A: the spider is a deliberate limit case, showing the triad's generality; the framework intends to cover biological signal processing.
READING B: covering biological signal processing is fatal, because it removes error, contestation, authority, and reversibility — the four things the dissertation's politics needs.

Reading B is supported by the archive's own priorities: every political question it asks requires a token that can be wrong.

MISSING:
Any statement of a necessary condition for descriptionhood anywhere in the archive. Twenty numbered sections of boundary questions, and no definition of the genus.

BOUNDARY:
Detachability is proposed here, not found in the source. It is a repair, and it may be too strong — indexicals and one-off utterances would need separate treatment.

CITATION TRAIL:
Ricoeur on distanciation and the semantic autonomy of the inscribed — PAPERS/ricoeur.md §II "From Speech to Text" and §IV "Action as Inscription". The archive already owns the criterion it needs, filed under hermeneutics rather than definition.

Any case that fails is not a case of operative description under the detachability condition, and its presence in the portfolio must be argued for separately.
