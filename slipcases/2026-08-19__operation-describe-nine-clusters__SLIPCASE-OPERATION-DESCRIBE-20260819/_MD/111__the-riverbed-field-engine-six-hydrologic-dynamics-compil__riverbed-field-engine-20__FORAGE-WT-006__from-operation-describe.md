TITLE: The Riverbed Field Engine: six hydrologic dynamics compile any source into a space-time constraint field

SOURCE: worldtext/syntheses/riverbed-field-engine.md — "Core Thesis", "The Core Law", "The Compilation Method", "Application to Worldtext Operations", "Mud as Resource"

PASSAGE: [QUOTE] "SPACE = constraint topology — zones, surfaces, distances, thresholds, paths, occlusions, interfaces, access rules, material resistance. TIME = transformation topology — moments, durations, intervals, rhythms, delays, recurrences, interruptions, traces, anticipations, returns, decay, acceleration. SPACE-TIME = a navigable field where every place carries duration and every duration occupies a place."

RESEARCH OBJECT: A universal compilation method that factors any source (idea, passage, image, scene, code system, world, prompt) into six dynamics: Riverbed (constraint), Water (motion), Sediment (trace), Erosion (transformation), Accretion (stabilization), Mud (ambiguity) — and emits a fixed 12-section "Riverbed Field Record" ending in a deployable prompt.

LOCAL MOVE: The file takes Wittgenstein's riverbed image (what "stands fast") and turns it from epistemology into a compiler pass: step 3 of the method is literally "Separate riverbed from water — What must remain constant for the source to remain itself? What is free to vary without destroying identity?"

SOURCE TERMS: Riverbed/Water/Sediment/Erosion/Accretion/Mud; constraint topology; transformation topology; operative field; mud literacy; the Ban List; Riverbed Field Record; "Keep it clear enough to steer and muddy enough to grow."

WHAT BECAME STRANGE: Ambiguity gets a positive slot in the type system. Mud is not noise to eliminate but a tracked resource: [QUOTE] "**Productive** when it fertilizes new structure — when unresolved mixture generates novel combinations that neither pure constraint nor pure variation could produce." A compiler with a deliberate undecided register.

QUESTION: Is the riverbed/water split of a given source unique, or can two competent operators compile the same source into different identity-partitions — and if so, what adjudicates?

DEEPER QUESTION: The file claims the riverbed/water distinction "is the **same** distinction as between World Bible and Lore Book" — is there really one master distinction (invariant vs. variation) underlying worldbuilding, epistemology, and prompt design, or does calling them "the same" flatten importantly different modal forces (physical necessity vs. editorial policy vs. cultural norm)?

MECHANISM: Steps 7–12 are a part-of-speech-to-operations transducer: [QUOTE] "Nouns → zones, objects, structures, traces, agents, thresholds, artifacts, temporal carriers; Verbs → forces, transitions, rhythms...; Adjectives → light, texture, pressure, density, tempo...; Emotions → climate and temporal tension: dread, suspension, urgency...; Relations → thresholds, bridges, gradients, interfaces, distances, overlaps, lags, synchronizations." Grammar categories become physical operators.

FORMAL SHIFT: From summarization (lossy compression of content) to field compilation (extraction of the constraint/variation structure that would let the content be *regenerated and steered*).

SOURCE FORMALISM: The six-element table (Element/Definition/Role: Constraint, Motion, Trace, Transformation, Stabilization, Ambiguity); the SPACE/TIME/SPACE-TIME core law; the 12-section output schema (FIELD NAME ... OPERATIVE PROMPT); the Ban List including [QUOTE] "'maybe,' 'perhaps,' 'it seems,' 'dreamlike,' 'surreal,' 'essence,' 'journey,' 'alchemy'", "Water that floods the riverbed", "Riverbed stated as optional detail"; and the mapping table Riverbed→World Bible, Water→Lore Book, Sediment→Encyclopedia, Erosion→Continuity Debt, Accretion→Canonization, Mud→unresolved mixture.

OUR FORMALIZATION: [OUR FORMALIZATION — NOT SOURCE SYNTAX] Source s compiles to F(s) = ⟨R, W, σ, ε, α, μ⟩ where R = invariant set, W = variation set with R ∩ W = ∅, σ: history → traces, ε: repeated W-events → ΔR (erosion as slow rewriting of invariants), α: σ-residue → new R members (accretion), μ = elements with undetermined membership; the engine's health condition is |μ| > 0 (productive) but μ ∩ control-critical = ∅ (dangerous mud).

TENSION: Erosion and Accretion both change R, contradicting the definition of Riverbed as "what must stand fast" — the engine's own dynamics guarantee that nothing finally stands fast; identity is only quasi-static. Rival readings: (a) this is Wittgenstein's own point (the bank shifts), faithfully mechanized; (b) it is an equivocation that lets the operator relabel any drift as "erosion" post hoc.

MISSING: Rates (how much erosion before identity is lost?); a decision procedure for mud triage ("mud literacy" is named but not proceduralized); any worked Riverbed Field Record example; validation that the 12-section record actually improves generation.

BOUNDARY: The engine compiles a single source into a single field; it has no story about composing two fields (two rivers converging) — which the worldtext graph handles instead.
