WHAT BECAME STRANGE: The typings are not aspects at different scales — they carry incompatible normative consequences. If a prompt is a ritual invocation (crn), it has a Role/Mood/WorldOrder and its analysis is liturgical; if it is circuit participation (cyber), the prompt has no standalone identity and analyzing "the prompt" alone is the failure mode; if it is an artifact entity (theory.json), it is precisely a standalone auditable object. cyber's typing forbids what theory.json's typing requires.

QUESTION: Which typing does the meta-program itself use when it treats <SourceText> + operator input as generative? (meta's own pipeline is prompt-driven but <Prompt> is absent from meta's entity list — the governing theory has no theory of its own input.)

DEEPER QUESTION: Is <Prompt> one entity six theories describe, or six entities sharing a token? The composition protocol's conflict check assumes the former (same name → compare definitions); a homonym reading would dissolve every flagged conflict in the corpus, which is why meta cannot afford it.

MECHANISM: Independent formalization of overlapping sources with no shared ontology layer; the manifest layer records theses, not entity signatures, so cross-file type collisions accumulate silently.

FORMAL SHIFT: From "the prompt" as an obvious interface object to prompt-as-contested-type whose typing determines the unit of ethical analysis (utterance vs rite vs circuit) — the clearest demonstration in the corpus that entity naming is theory choice.
