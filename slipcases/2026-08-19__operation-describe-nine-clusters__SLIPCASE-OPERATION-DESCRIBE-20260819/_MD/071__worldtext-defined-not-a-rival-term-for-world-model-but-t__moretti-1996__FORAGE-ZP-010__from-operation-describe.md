TITLE: Worldtext defined: not a rival term for world model but the moment description becomes an interface to one

SOURCE: Z-Port/final-draft-v2.md §1 and §3; Z-Port/worldtext-after-ekphrasis.md (opening + §4); Z-Port/image-is-not-end-of-ekphrasis.md §4 and §8; Z-Port/A-TEST/c-1.md (Introduction); Z-Port/final-assembled-draft.md §3 (Moretti addition)

PASSAGE: [QUOTE] "Worldtext is not a rival term for world model. Worldtext names the moment when description becomes an interface to a world model. That distinction matters because it keeps the humanistic question alive inside the technical one: not simply *how* does the model generate a world, but *what kind of world* does the description authorize?" (final-draft-v2.md §1) [QUOTE] "A worldtext is a textual operation through which a world becomes available as a coherent field of relations." (worldtext-after-ekphrasis.md, opening) [QUOTE] "Image generation asked: what can a sentence make visible? World generation asks: what can a sentence make habitable?" (final-draft-v2.md §3) [QUOTE] "Moretti (1996) had already named this ambition in his reading of the epic, calling it directly a 'world text' — a textual artifact compressing a totality of social relations onto a single bounded surface." (final-assembled-draft.md §3) [QUOTE] "Once the image can be entered, the old question returns in a harsher form: what kind of life has the description authorized?" (final-assembled-draft.md §4; originating in image-is-not-end-of-ekphrasis.md)

RESEARCH OBJECT: The paper's central coinage as a threshold concept with a carefully policed extension: worldtext ≠ world model (technical structure) and ≠ worldbuilding/lore/setting; it names a media-theoretical condition — language operating as interface to a stateful environment. Its differentia from imagetext: "The imagetext merges word and image into a single artifact. The worldtext merges word, image, space, time, interaction, and governance into a single environment" (v2 §3). Its ethical payload is the authorization question, which the section-comparison identifies as D's unique contribution ("elevates the paper from epistemological... to ethical/political").

LOCAL MOVE: Coin the successor term but immediately bind it to modesty clauses — "threshold, not the triumph" (worldtext-after-ekphrasis §4), "the paper stops where the door opens" — so the concept claims novelty while disclaiming arrival; the deep-research-report confirms this is required ("'worldtext'... not current consensus terms... present them as a proposed conceptual advance").

SOURCE TERMS: worldtext; threshold concept; interface to a world model; coherent field of relations; visible vs habitable; depiction vs state; affordance; "an image under conditions"; authorization

WHAT BECAME STRANGE: The final-assembled draft's Moretti insertion quietly changes the coinage's status: "world text" already existed (Moretti 1996, Modern Epic) for artifacts compressing social totality — so the paper's new term has an unacknowledged prior life, and the novelty claim shifts from the word to the interface-condition it now names.

QUESTION: What is the minimal sufficient condition for worldtext — persistence? interactivity? consequence? The drafts give a candidate: "Without consequence, worldtext is only scenery with ambition" — but never define consequence operationally.

DEEPER QUESTION: Can the humanistic question really be kept "alive inside the technical one" by a terminological distinction — or does the interface-concept inevitably get absorbed by the technical term the way "imagetext" was absorbed by "latent space"?

MECHANISM: Threshold-naming: identify the point where an existing concept's object changes state (image → environment), coin a term for the crossing rather than the destination, and predict the term's own divergence ("the concepts forced together in this moment of convergence... will inevitably diverge" — word-to-world.md §IV).

FORMAL SHIFT: The evaluative frame for generated media shifts from accuracy (does output resemble prompt?) to authorization (what rules, defaults, exclusions, affordances, forms of life did the description activate?) — "Accuracy belongs to a representational frame. Worldtext requires an operational frame" (worldtext-after-ekphrasis §6).

SOURCE FORMALISM: d-1/image-is-not-end §8 progression schema: "word → image (traditional ekphrasis) / prompt → generated image (operative ekphrasis) / prompting loop → constrained generation (thick prompting) / description stack → stateful environment (worldtext)".

OUR FORMALIZATION: [OUR FORMALIZATION — NOT SOURCE SYNTAX] Worldtext(d) holds iff execute(d) yields environment W with: state persistence (W_t depends on W_{t-1}), interaction (user actions a alter W), and governance (constraints specify permitted transitions); evaluation function shifts from sim(output, d) to the affordance profile A(W) = (allowed, remembered, easy, impossible, natural, unthinkable) — the six-slot politics list from v3 §4.

TENSION: READING A: worldtext is a genuinely new object requiring new theory (the qualitative-difference claim). READING B: worldtext is a "bigger imagetext" after all — the drafts must repeatedly deny this ("The worldtext is not a bigger imagetext") precisely because every listed ingredient (word, image, constraint) was already in the imagetext account, and current platforms deliver "navigable surfaces without deep social, physical, or narrative coherence" (worldtext-after-ekphrasis §4), i.e., scenery with ambition.

MISSING: An actual worked example of a generated world read through the authorization question — the corpus poses "what kind of life has the description authorized?" but never answers it for any real Genie/Marble output; Moretti's actual argument (Modern Epic) is asserted in one sentence, unverified page or context.

BOUNDARY: Explicitly excluded from worldtext: lore, fictional geography, worldbuilding "in the ordinary sense," game maps with narrative decoration (worldtext-after-ekphrasis opening; c-1 Introduction).

CITATION TRAIL: Mitchell 1994 (imagetext, the exceeded predecessor) → Bajohr 2024 (operative ekphrasis, the first threshold) → Ha & Schmidhuber 2018 / LeCun 2022 / Bruce et al. 2024 / World Labs (the technical referent) → Moretti 1996 (the unacknowledged-then-acknowledged precedent) → Davis 2011/2015 (theological residue, cited inconsistently by year across v4 and final-assembled).

TEST: Take one Genie 2 or Marble generation from a documented prompt and produce its affordance profile A(W); if the six slots can be filled with observable properties, worldtext is operational; if not, it remains programmatic vocabulary.

PLATFORM: Genie 2 (DeepMind), Marble (World Labs), Meta V-JEPA 2 (research-report only) as the systems the concept indexes.
