TITLE: The corpus contains two Geertzes: thick.json types culture as a control program; tda.json's final theorem denies culture is a program at all

SOURCE: PROGRAMS/thick.json — <Initial_Interpretation>, <invariants>, <culture_model>; PROGRAMS/tda.json — <FINAL_THEOREM>; both HERMENEUTIC lineage per meta.json CORPUS_MANIFEST

PASSAGE: [QUOTE thick.json] "<culture> [is-not] <ornament> <culture> [is] <extra-genetic instruction system>"; "<culture> [contains] {plans, recipes, rules, instructions, symbols, rituals, etiquette, institutions} <culture> [governs] <behavior> ... <culture> [narrows] <general_capacity> <culture> [produces] <particular_personhood>". [QUOTE tda.json] "<culture> is not the hidden program beneath action. <culture> is the contested public world in which action becomes legible."

RESEARCH OBJECT: An entity-conflict in meta.json's exact technical sense: both theories name entity <culture>, and definition(thick.culture) contradicts definition(tda.culture) on the load-bearing predicate is-a-program. Both derive from Geertz — thick from "The Impact of the Concept of Culture on the Concept of Man" (control-mechanism Geertz), tda from "Thick Description" (public-discourse Geertz, contra the "culture as recipe" reading Geertz himself later distanced).

LOCAL MOVE: Put the two culture-definitions side by side and refuse the easy harmonization ("different emphases"); test whether each theory's failure modes fire on the other.

SOURCE TERMS: extra-genetic instruction system; control_mechanism; compiled_personhood; contested public world; hidden program beneath action; MECHANISM_REDUCTION_ERROR

WHAT BECAME STRANGE: thick.json anticipates the attack and builds a firewall — failure MECHANISM_REDUCTION_ERROR: "<culture_as_program> [is_read_as] <deterministic_code> → <meaning> [is_erased]" — so thick's program-talk is declared "analytic_metaphor, not deterministic_reduction". But tda's theorem denies the metaphor itself, not just its deterministic reading: culture is not a program beneath action, hidden or soft. The disagreement survives thick's own hedge; it is about where culture is (beneath action, compiling it vs. in public, making it legible), not how hard it determines.

QUESTION: When the HERMENEUTIC suite deploys (CLAUDE.md standard deploy: mot → tah → tda → thick → dse), what does an artifact reading look like at the tda→thick seam, where the fourth lens asserts what the third just denied?

DEEPER QUESTION: Is this contradiction Geertz's own — the 1966 cybernetic Geertz vs the 1973 anti-cognitivist Geertz — faithfully preserved by the formalization? If so, the corpus has done something rare: formalized an author's self-contradiction into two machines that can be run against each other.

MECHANISM: Same source author formalized twice from different essays; lineage assignment groups them, and the composition protocol's within-lineage assumption ("no conflicts expected within lineage" — CLAUDE.md) masks the conflict from the audit.

FORMAL SHIFT: From a philological dispute about Geertz interpretation to a machine-checkable definitional conflict: contradicts(def_A(culture), def_B(culture)) instantiated with real content for the first time in the corpus.

SOURCE FORMALISM: thick's culture_model operator chains; tda's FINAL_THEOREM prose-with-brackets.

OUR FORMALIZATION: [OUR FORMALIZATION — NOT SOURCE SYNTAX] thick: culture: Capacity → Performance (a function applied to the unfinished animal; personhood is its runtime output). tda: culture: Action → Legibility (a context, i.e., not a function on agents but a space in which actions acquire readability; explicitly not an element of the function type). The conflict is a type-level disagreement: Program(culture) vs Context(culture), and no subtyping relation reconciles a function with the space it would run in.

TENSION: Rival reading (harmonizing): thick describes culture ex ante (instructing action), tda ex post (interpreting action); a two-phase model could hold both. But thick's invariant "<human> [has_no] <pre-cultural_backstage>" and tda's "answerable_to_case" both claim the whole phenomenon, not a phase. The corpus's honest state is flagged-conflict-awaiting-operator-ruling; the manifest instead lists the pair as productive tension ("Thick Description ↔ Thick Programming"), which under meta's own definitions is a misclassification.

MISSING: An operator ruling; a synthesis page staging the conflict; acknowledgment anywhere that the two theses cannot both anchor the same suite without a ruling.

BOUNDARY: The conflict is over <culture> only; the two theories' method-level machinery (read meaning AND operation; interpretation answerable to case) is compatible and even complementary.

CITATION TRAIL: Geertz 1966 "Impact of the Concept of Culture..." → thick.json; Geertz 1973 "Thick Description: Toward an Interpretive Theory of Culture" → tda.json; meta.json cross_references "tda.json ↔ thick.json".
