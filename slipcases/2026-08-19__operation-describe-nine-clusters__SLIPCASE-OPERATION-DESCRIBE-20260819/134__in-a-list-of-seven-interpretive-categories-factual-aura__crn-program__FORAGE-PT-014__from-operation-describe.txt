TITLE: In a list of seven interpretive categories, "factual aura" is the only one that names an effect on audiences — and therefore the only one that can be measured

SOURCE: PROGRAMS/crn.json — Cybernetic Ritual Narratology Engine v1.1, <Initial Interpretation>

PASSAGE: [QUOTE] "<core claim> := '<GenerativeAI> [is-not] <tool-alone> <GenerativeAI> [is-not] <muse-alone> <GenerativeAI> [is] <recursive-cultural-apparatus>'" [QUOTE] "<engine purpose> := 'Convert an AI-mediated artifact into a map of symbolic action, distributed agency, inherited cultural grammar, narrative world-making, factual aura, feedback, and ethical risk.'"

RESEARCH OBJECT: Factual aura — the impression that a generated artifact reports rather than invents. Six of the engine's seven output categories are analyst judgments about the artifact. This one is a disposition in viewers, which means it has a rate.

LOCAL MOVE: The theory treats generation as ritual: prompts as invocations, datasets as compressed cultural memory, outputs as artifacts that circulate and acquire authority.

SOURCE TERMS: recursive cultural apparatus / symbolic action / distributed agency / inherited cultural grammar / narrative world-making / factual aura / feedback / ethical risk

WHAT BECAME STRANGE: Aura in Benjamin is tied to the presence of an original and is destroyed by reproduction. Here it appears where there is *no* original at all — a generated image has no thing it was taken from, yet it carries evidential force. That is not diminished aura; it is aura without a referent, which the concept was not built to describe.

QUESTION: Is factual aura a property of the artifact, of the interface that presents it, or of the ritual through which it was made?

DEEPER QUESTION: If interface framing dominates artifact content, then credibility is an interface variable — and the ethics of generated media is a presentation-design problem before it is a generation problem.

MECHANISM: <GENERATED ARTIFACT> -> [PRESENTED IN AN EVIDENTIAL FRAME: caption, source line, resolution, grain, UI chrome] -> viewer assigns provenance -> <BELIEF> -> [CIRCULATION] -> frame strengthens as others treat it as evidence

FORMAL SHIFT: <OUTPUT> -> <FRAMED ARTIFACT> -> [CREDENCE ASSIGNMENT] -> <EVIDENTIAL FORCE WITHOUT A REFERENT>

SOURCE FORMALISM: The seven-category mapping.

OUR FORMALIZATION: [OUR FORMALIZATION — NOT SOURCE SYNTAX] aura(a, f) = mean viewer credence that a depicts something that occurred, under frame f. Then decompose variance between artifact and frame. The ratio is the finding.

TENSION: READING A: aura is in the artifact — photorealism and grain produce it, so it is a generation problem. READING B: aura is in the frame — the same image in a news layout and a gallery wall gets different credence, so it is a presentation problem.

MISSING: Any credence measurement. Any account of how aura behaves after a viewer learns the image is generated — does it decay, and how fast?

BOUNDARY: Benjamin's aura concerns authenticity and cult value; "factual aura" is a different object wearing the word, and the borrowing needs defending rather than assuming.

CITATION TRAIL: Benjamin, "The Work of Art in the Age of Mechanical Reproduction." Source-credibility literature. Provenance standards such as C2PA. [[FORAGE-PT-011]] [[FORAGE-PT-012]]

TEST: One generated image, three frames (news caption / art caption / unlabelled), twenty viewers each, credence rated. Then disclose and re-rate. Variance between frames versus within frames locates the aura; the decay after disclosure measures whether it can be undone.
