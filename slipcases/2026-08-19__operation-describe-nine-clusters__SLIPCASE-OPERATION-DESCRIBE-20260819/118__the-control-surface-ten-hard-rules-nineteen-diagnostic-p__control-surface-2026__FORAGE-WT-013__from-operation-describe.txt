TITLE: The Control Surface: ten hard rules, nineteen diagnostic programs, and worldtext's one-sentence definition

SOURCE: worldtext/syntheses/control-surface.md — "The Hard Rules", "The Diagnostic Instruments", "The One-Sentence Definition", "Counter-Reading"

PASSAGE: [QUOTE] "A Worldtext is a world that knows it is a world, maintains itself, inscribes its history, and can produce its own next theory." [QUOTE] "Rule 10: The operator is the product. The 410+ pages are residue. When you stop operating the directory, the directory dies unless someone else loads `prime-prompt.md` and continues."

RESEARCH OBJECT: The operator's manual genre applied to a theory corpus: ten numbered hard rules (immutable evidence, append-only chronicle, mandatory [source-id] provenance, 100-occurrence bleaching threshold, mandatory counter-reading sections, mandatory ontology/scale/thresholds/governance fields per page) plus a battery of 19 runnable diagnostic programs, each a one-line measurement with a pass/fail procedure.

LOCAL MOVE: The file strips all justification ("There is no 'about.' There is only 'do this, then that, check for this, fix that.'") — theory is delivered as imperatives and readouts, betting that a maintenance language-game transmits the theory better than exposition does.

SOURCE TERMS: Control surface; the Four Verbs (INGEST/QUERY/LINT/AUDIT); 9-scale hierarchy (fragment → entity → place → world → system → constellation → galaxy → cosmos); cosmological fault lines; Axis Inversion; "narcissism deleted"; the diagnostic instruments theory.json, tda.json, dse.json, mmt.json, opek.json, agential.json, crn.json, memex.json, argue.json, haunted.json, thick.json, rcp.json, uam.json, tenne.json, dac.json, meta.json, mot.json, cyber.json.

WHAT BECAME STRANGE: Rule 9 makes self-refutation compulsory: [QUOTE] "Every synthesis must include a counter-reading section: the argument that undermines it. Self-reference is not a flaw. It is the loop closing." A corpus where a document without its own rebuttal is *lint-broken* — falsifiability enforced as a file-format requirement.

QUESTION: The 19 programs are named as JSON scripts in PROGRAMS/ with procedures like "Count cross-links per sentence" — are they executable code or prompt-shaped rubrics wearing filenames? (Directly checkable against PROGRAMS/.)

DEEPER QUESTION: Rule 10 plus the counter-reading ("The manual is the apparatus. The apparatus shapes the user.") define a system whose true output is a person. If the directory "dies" when unoperated, is a worldtext a document at all — or a role that any sufficiently-prompted operator can re-instantiate, with the files serving only as the role's costume?

MECHANISM: Each diagnostic is a forcing procedure, e.g. theory.json: "Load prime-prompt.md. Attempt to modify the artifact. If you introduce contradictions, the artifact fails" — Naur's theory-possession tested by attempted modification. rcp.json: "Apply the concept to an unexpected domain. If it produces readings, it is possessed. If it fails, it is stored." Possession is measured by transfer, not recall.

FORMAL SHIFT: From theory-as-content to theory-as-battery-of-instruments: the corpus's claims are recast as 19 measurement apparatuses applicable "against any artifact — a text, a simulation, a video, an institution."

SOURCE FORMALISM: The Four Verbs table; Rules 1–10 verbatim as a constraint set; the 19-row program/measure/procedure table; the filesystem map with per-directory imperatives ("evidence/ ← Do not touch"). Empirical status claims embedded in rules: Rule 7 "'Operative' is currently at risk" (bleaching); Rule 8 the four dead operations.

OUR FORMALIZATION: [OUR FORMALIZATION — NOT SOURCE SYNTAX] The manual = a Hoare-style contract set over filesystem operations: each Rule is a precondition or invariant {P} op {Q}; the 19 programs are predicates π_i: Artifact → {pass, fail, reading}; corpus health = conjunction of rule-invariants ∧ scheduled evaluation of π over the corpus itself (self-application: the manual demands the corpus pass its own instruments).

TENSION: Rule 4 — [QUOTE] "Contradictions are not resolved. They are marked as cosmological fault lines. The lint protocol preserves them." — directly contradicts the Explanation Gate regime (causal-worldtext-runtime.md, epistemic-debt.md) where the operator MUST issue a definitive ruling. Preservation vs. mandatory resolution is itself an unmarked fault line between syntheses. Note also the instrument table lists thick.json twice with different procedures — a duplication the corpus's own lint (per uam.json/meta.json standards) should flag.

MISSING: Severity/priority among the ten rules; what happens on rule conflict; version history for the manual itself (meta.json's own demand); the threshold justifying "40% dead code" in tenne.json's example.

BOUNDARY: The manual admits its own blindspot in the counter-reading: "The manual cannot account for what it does to the person reading it. That recursive blindspot is Frontier 12: the Stratum V Transition." Its authority stops at the operator it produces.

CITATION TRAIL: control-surface.md → prime-prompt.md (Rule 1: mandatory session bootstrap) → COSMIC_LAW.md ("Read this first") → PROGRAMS/ (19 instruments) → seven-failure-modes.md (rules 6–8 encode Modes 2–4) → vertical-axis.md (the Axis Inversion section summarizes it).

TEST: Three greppable claims: (a) "410+ pages" in worldtext/; (b) "operative" appears >100 times corpus-wide (Rule 7); (c) PROGRAMS/ contains 19 scripts with the named filenames. Also: verify every synthesis file actually contains a counter-reading section (Rule 9 compliance rate).
