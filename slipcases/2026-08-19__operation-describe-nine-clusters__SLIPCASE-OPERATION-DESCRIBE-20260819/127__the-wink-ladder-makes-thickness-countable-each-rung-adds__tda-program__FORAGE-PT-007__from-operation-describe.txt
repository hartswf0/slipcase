ZETTEL

ID: FORAGE-PT-007

TITLE: The wink ladder makes thickness countable: each rung adds one intention *about* the rung below it

SOURCE: PROGRAMS/tda.json — THICK_DESCRIPTION_AFTER_THE_EVENT, <PURPOSE> and the wink rules

PASSAGE: [QUOTE] "How does <meaningful_action> survive after <the_event> disappears?" [QUOTE] "IF <purpose> [is] <ridicule> THEN OUTPUT <parody> IF <eyelid_contraction> [prepares] <future_parody> THEN OUTPUT <rehearsal>"

RESEARCH OBJECT: A rule set that generates a ladder — contraction, wink, parody of a wink, rehearsal of a parody of a wink — where each rung is an intention taking the previous rung as its object. Thickness stops being an atmosphere and becomes an integer: the depth of intentional embedding required to describe the act correctly.

LOCAL MOVE: The theory renders Geertz's wink as production rules with conditions and outputs, which exposes what the prose kept implicit: the levels are recursive and the recursion has a depth.

SOURCE TERMS: eyelid contraction / ridicule / parody / rehearsal / prepares / meaningful action / after the event

WHAT BECAME STRANGE: The ladder has no top. Nothing in the rules stops rung five. And thickness — a term used across the whole field as a quality — turns out to have a natural unit that nobody counts.

QUESTION: Is descriptive thickness just embedding depth, and can human readers and machine systems both recover the depth of a given act?

DEEPER QUESTION: If depth is the unit, then "thick description" and "theory of mind order" are the same measurement under two disciplinary names — and the ethnographic and the cognitive-science literatures have been measuring one thing separately for fifty years.

MECHANISM: <PHYSICAL ACT> -> [ATTRIBUTE INTENTION] -> rung 1 -> [ATTRIBUTE INTENTION ABOUT RUNG 1] -> rung 2 -> ... each rung requires the reader to hold all below it

FORMAL SHIFT: <BEHAVIOUR> -> <NESTED INTENTION STACK> -> [DEPTH COUNT] -> <THICKNESS AS AN INTEGER>

SOURCE FORMALISM: The IF/THEN production rules quoted above.

OUR FORMALIZATION: [OUR FORMALIZATION — NOT SOURCE SYNTAX] depth(a) = least n such that a correct description of a requires n nested intention operators. contraction = 0; wink = 1; parody = 2; rehearsal = 3.

TENSION: READING A: thickness is embedding depth, countable, and comparable across cases. READING B: thickness is also *breadth* — the number of distinct contexts a description must invoke — and collapsing it to depth loses the webs-of-significance claim entirely.

MISSING: Any counted case. Any test of whether readers agree on the depth of a given act.

BOUNDARY: Geertz never quantifies. Depth is legible in this rule set because the rule set was written; it is not Geertz's claim.

CITATION TRAIL: Geertz, "Thick Description," in The Interpretation of Cultures (1973). Higher-order theory-of-mind measurement in cognitive science. [[FORAGE-PT-018]] [[FORAGE-PT-024]]

TEST: Construct stimuli at depths 0-4 and ask both human readers and a model to produce a correct description. Score maximum recoverable depth for each. If the two ceilings differ, that gap is a concrete, measured difference in descriptive capacity — and thickness has a number for the first time.
