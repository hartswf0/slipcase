TITLE:
As interfaces absorb craft, authorship can become easier while expertise disappears

SOURCE:
Shambibble — interview with Watson Hartsoe — October 22, 2022 — 48:53–51:32. fileciteturn3file0L55-L63

PASSAGE:
[PARAPHRASE]
Shambibble speculates that “prompt crafting” might disappear as natural-language processing improves: instead of learning special prompt techniques, users may simply state what they want. He also anticipates real-time GUI controls and brushes making generative editing more direct. fileciteturn3file0L55-L59

RESEARCH OBJECT:
Prompt expertise and authorial control may move in opposite directions.

As systems become easier to use, the specialized skill of prompting can vanish while expressive control becomes stronger.

LOCAL MOVE:
The source historicizes prompt craft as a temporary response to interface failure rather than a permanent artistic medium.

SOURCE TERMS:
prompt crafting
natural language processing
tell it what you want
GUI
real time
brushes
see what your changes are doing

WHAT BECAME STRANGE:
If difficulty were evidence of authorship, better interfaces would perversely reduce authorship.

But the source predicts the reverse causal structure:

less specialized effort
+
more immediate feedback
=
greater control.

QUESTION:
Why should the difficulty of making an instruction legible to a machine matter to authorship at all?

DEEPER QUESTION:
Is prompt craft partly friction produced by an immature interface rather than the locus of the creative act?

MECHANISM:
weak interpreter
→ specialized prompt hacks
→ high expertise / low directness

improved interpreter + interactive controls
→ ordinary language / local edits
→ lower expertise / greater addressability

FORMAL SHIFT:
<CRAFT AS COMPENSATION FOR INTERFACE FAILURE>
→ <INTERFACE IMPROVEMENT>
→ [ABSORB TECHNIQUE INTO SYSTEM]
→ <DIRECTER CONTROL WITH LESS VISIBLE SKILL>

SOURCE FORMALISM:
NONE

OUR FORMALIZATION:
[OUR FORMALIZATION — NOT SOURCE SYNTAX]

Early system:

EFFORT ↑
CONTROL uncertain

Later system:

EFFORT ↓
CONTROL ↑

Therefore:

EFFORT is not a reliable proxy for AUTHORSHIP.

TENSION:
Prompt communities often treat difficult-to-discover techniques as marks of creative mastery.

Yet [[BGS-1884-25]] shows those techniques can become buttons, while this source predicts that entire categories of prompt expertise may disappear.

What remains when the craft is compiled into the interface?

MISSING:
A medium-independent account of authorship that survives the disappearance of technical friction.

BOUNDARY:
The passage is explicitly speculative. It predicts possible interface development; it does not establish that prompt craft actually disappears.

CITATION TRAIL:

TEST:
Implement the same generative operation through three interfaces:

1. obscure prompt syntax
2. ordinary natural language
3. direct manipulation GUI

Hold resulting control constant.

Ask whether any authorship theory changes merely because expertise and effort required to exercise the operation collapse.
