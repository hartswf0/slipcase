# Prompt Craft as Probabilistic Control

Derived MOC. Archived zettel payloads remain unchanged.

- [[BGS-1884-18]] — The copyrightability of prompting may change without the law changing at all
- [[BGS-1884-19]] — Human control may operate by loading the dice rather than choosing the result
- [[BGS-1884-20]] — An instruction can create by eliminating futures it never explicitly describes
- [[BGS-1884-21]] — A prompt history records intentions; an authorship history would have to record effects
- [[BGS-1884-22]] — Prompt craft is not speaking a language; it is reverse-engineering one that never published its grammar
- [[BGS-1884-25]] — A user can invent an operation before the platform admits that the operation exists
- [[BGS-1884-26]] — Control can come from decomposing one impossible instruction into several partially independent ones
- [[BGS-1884-27]] — Selection stops looking terminal when the human has already engineered what the machine is allowed to vary
- [[BGS-1884-28]] — As interfaces absorb craft, authorship can become easier while expertise disappears
