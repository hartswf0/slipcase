TITLE:
A user can invent an operation before the platform admits that the operation exists

SOURCE:
Shambibble — interview with Watson Hartsoe — October 22, 2022 — 09:48–11:04. fileciteturn3file3L383-L397

PASSAGE:
[PARAPHRASE]
Shambibble describes reconstructing an old job through its job ID, seed, prompts, and remastering workflow to achieve behavior the interface did not expose directly. He then publicized the technique until, as he puts it, “they made it a thing until they made it a button.” fileciteturn3file3L391-L397

RESEARCH OBJECT:
Control is not merely supplied by an interface.

Users can discover latent operations, stabilize them as practices, and force them upward into interface design.

LOCAL MOVE:
The practitioner describes a capability migrating:

accidental possibility
→ user hack
→ repeatable community technique
→ official interface feature.

SOURCE TERMS:
job ID
seed
prompts
custom
remastered
hack
made it a thing
button

WHAT BECAME STRANGE:
[[BGS-1884-18]] made authorship contingent on interface capabilities.

But interfaces are not external givens.

The creators themselves can participate in inventing the control surface by discovering how the system can be made to behave.

QUESTION:
If a creator discovers a latent control operation that the system’s designers did not expose, who authored the capability being exercised?

DEEPER QUESTION:
Can the authorship of an artifact depend on a control grammar partly invented by the artifact’s user?

MECHANISM:
platform exposes low-level fragments
→ user combines fragments unexpectedly
→ new reproducible operation appears
→ community circulates operation
→ vendor formalizes operation
→ operation becomes button

FORMAL SHIFT:
<LATENT CAPABILITY>
→ <USER DISCOVERY>
→ [SOCIAL STABILIZATION]
→ <INTERFACE PRIMITIVE>

SOURCE FORMALISM:
NONE

OUR FORMALIZATION:
[OUR FORMALIZATION — NOT SOURCE SYNTAX]

C₀ = vendor-exposed capabilities

User composes:

h(C₀) → c_new

Later:

c_new ∈ C₁

where C₁ is the next official interface.

The control surface has a genealogy.

TENSION:
If copyrightability changes because the later button offers more explicit control, the same underlying operation could appear less authorial when performed as a hack than when formalized by the vendor.

That would make legal attribution sensitive to interface packaging rather than causal operation.

MISSING:
A way of describing user-discovered control independently of whether the vendor has named or formalized it.

BOUNDARY:
The interview establishes Shambibble’s account of this feature genealogy. It does not independently verify priority or the platform team’s reasons for later interface changes.

CITATION TRAIL:

→ user-discovered job-ID/remaster workflow

→ trace latent affordance → vernacular technique → official feature

TEST:
Find an operation that existed both before and after becoming an official interface control.

Recreate equivalent artifacts using:

A. pre-feature hack
B. later official control

Compare the actual causal leverage over the artifact rather than the apparent usability of the interface.
