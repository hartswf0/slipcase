TITLE:
Automatic prompt optimization can make the machine teach the human how the machine prefers to be addressed.

SOURCE:
Yaru Hao, Zewen Chi, Li Dong, and Furu Wei — “Optimizing Prompts for Text-to-Image Generation” — 2022; Datta et al. — Prompt Expansion — 2024.

PASSAGE:
[PARAPHRASE]
Prompt optimizers transform ordinary user language into model-preferred descriptions selected for generation quality while attempting to preserve user intent.

RESEARCH OBJECT:
THE OPERATIVE LANGUAGE MAY BELONG MORE TO THE MODEL THAN TO THE USER.

LOCAL MOVE:
The effective prompt can be an engineered machine dialect invisible to its nominal speaker.

SOURCE TERMS:
prompt adaptation
model-preferred prompts
user intention
optimization
prompt expansion
text-to-image

WHAT BECAME STRANGE:
A user may communicate in ordinary language while a second system manufactures the operative sociolect.

QUESTION:
Is artistic prompting still a linguistic practice of the user when the language that directly controls generation is automatically manufactured downstream?

DEEPER QUESTION:
Who possesses operative literacy when translation from human intention into model-effective language is automated?

MECHANISM:
H → q → optimizer O → p* in model-preferred dialect → G → image.

FORMAL SHIFT:
<HUMAN OPERATIVE LITERACY> → <AUTOMATED TRANSLATION INTO MACHINE DIALECT>

SOURCE FORMALISM:
Prompt adaptation optimizes downstream generation while retaining an estimate of intent.

OUR FORMALIZATION:
[OUR FORMALIZATION — NOT SOURCE SYNTAX]
L_H = language of intention; L_M = language of effective control; O:L_H→L_M.

TENSION:
Automating machine dialect can democratize access rather than diminish agency.

MISSING:
Whether users who never see p* can distinguish when O materially alters expressive constraints.

BOUNDARY:
Control does not require authorship of every intermediate representation, but hidden transformation changes the attribution path.

TEST:
