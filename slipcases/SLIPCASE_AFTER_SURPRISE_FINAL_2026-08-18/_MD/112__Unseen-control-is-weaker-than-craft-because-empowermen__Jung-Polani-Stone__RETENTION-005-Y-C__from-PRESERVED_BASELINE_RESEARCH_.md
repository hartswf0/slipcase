ID:
RETENTION-005-Y-C

TITLE:
Unseen control is weaker than craft because empowerment couples controllability to what the agent can perceive.

SOURCE:
Tobias Jung, Daniel Polani, and Peter Stone — “Empowerment for Continuous Agent-Environment Systems” — 2011.

PASSAGE:
[PARAPHRASE]
Empowerment joins the capacity to affect the environment with the capacity to sense resulting differences; hidden causal changes unavailable to observation cannot support the same feedback control.

RESEARCH OBJECT:
PERCEPTIBLE CONTROL.

LOCAL MOVE:
Add CAN THE MAKER TELL WHICH DIFFERENCE THEIR ACTION MADE?

SOURCE TERMS:
empowerment
controllability
observability
sensor
influence
successor state

WHAT BECAME STRANGE:
A user can cause differences in hidden state yet be unable to learn to steer them.

QUESTION:
Should artistic control require not merely causal influence but a closed perceptual loop through which the maker can discriminate intervention consequences?

DEEPER QUESTION:
Is craft the learned exploitation of an observable control channel?

MECHANISM:
a→hidden h→observation o; if h1/h2 differ but Observation(h1)=Observation(h2), feedback cannot discriminate them.

FORMAL SHIFT:
<CAUSAL INFLUENCE> + <OBSERVABILITY> → <LEARNABLE CONTROL>

SOURCE FORMALISM:
Empowerment is an information-theoretic combination of influence and sensed influence.

OUR FORMALIZATION:
[OUR FORMALIZATION — NOT SOURCE SYNTAX]
Craft-relevant channel A→System→O_artist; CraftControl∝I(A;O_future), not action→hidden state alone.

TENSION:
Artists can exploit effects without mechanistic understanding if those effects are perceptibly repeatable.

MISSING:
How much repeatability/perceptibility converts influence into usable technique.

BOUNDARY:
Control that cannot return as discriminable feedback may be causal agency without practical craft.

CITATION TRAIL:
[[RETENTION-005-Y]] → empowerment → controllability + observability → craft feedback loop.

TEST:
Create two controls with equal hidden causal influence but hide relevant output difference for one; test learning of repeatable steering.
