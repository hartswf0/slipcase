TITLE:
Prompt expansion turns underspecification into a machine-controlled exploration variable rather than a defect to be eliminated.

SOURCE:
Siddhartha Datta et al. — “Prompt Expansion for Adaptive Text-to-Image Generation” — ACL 2024.

PASSAGE:
[PARAPHRASE]
Prompt Expansion creates multiple expanded prompts designed for diverse, appealing results, treating uncommitted aspects of the query as room for variation.

RESEARCH OBJECT:
UNSPECIFIED CONTENT CAN BE TREATED AS GENERATIVE FREEDOM.

LOCAL MOVE:
Underspecification may be a resource deliberately handed to the machine, not merely missing instruction.

SOURCE TERMS:
prompt expansion
diversity
appealing images
user query
expanded prompts
adaptive generation

WHAT BECAME STRANGE:
The user can potentially author the limits of discretion rather than every value within them.

QUESTION:
How can we distinguish accidental underinstruction from intentional delegation of exploratory freedom?

DEEPER QUESTION:
Should an artist be able to author the BOUNDARY of machine discretion without authoring values chosen inside that boundary?

MECHANISM:
user fixes C_fixed and leaves V_open; expansion proposes assignments to V_open → multiple prompt/image families.

FORMAL SHIFT:
<UNSPECIFIED = MISSING> → <UNSPECIFIED = DELEGATED POSSIBILITY SPACE>

SOURCE FORMALISM:
Prompt Expansion generates a set of expanded prompts and evaluates quality/diversity.

OUR FORMALIZATION:
[OUR FORMALIZATION — NOT SOURCE SYNTAX]
Distinguish Omission(v) from Delegation(v). Delegation requires evidence the user intentionally leaves v open for downstream resolution.

TENSION:
Most interfaces lack syntax distinguishing intentional delegation from accidental omission.

MISSING:
Controls such as FIX THIS / EXPLORE THIS / SURPRISE ME.

BOUNDARY:
Machine-added detail is not necessarily unauthorized; status depends on allocated discretion.

CITATION TRAIL:
[[RETENTION-005-N-A]] → prompt expansion → diversity → uncommitted variable as delegated exploration.

TEST:
Build LOCK/RANGE/SURPRISE ME interface and compare attribution/control to ordinary underspecified prompting.
