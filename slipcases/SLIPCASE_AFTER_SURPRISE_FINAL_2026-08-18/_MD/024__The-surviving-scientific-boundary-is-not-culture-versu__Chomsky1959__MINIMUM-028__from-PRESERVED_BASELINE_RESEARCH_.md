ZETTEL

ID:
MINIMUM-028

TITLE:
The surviving scientific boundary is not culture versus code but specified uptake versus underspecified uptake.

SOURCE:
COLLISION — Chomsky 1959; SCXML 2015; Bourdieu 1977; Deleuze and Guattari 1987; Winograd 1971; probabilistic operational semantics 2012. 26

PASSAGE:
[PARAPHRASE]
Across the sources, symbolic systems become consequential through very different receivers: rewrite systems, standardized processors, social dispositions, institutions, natural-language interpreters, and probabilistic evaluators.

RESEARCH OBJECT:
OPERATIVITY admits degrees and types.

LOCAL MOVE:
The lineage no longer supports a single anvil on which “mere description” becomes “true execution.”

It supports a stack of increasingly constrained relations.

SOURCE TERMS:
derivation
processor
practice
assemblage
procedure
operational semantics

WHAT BECAME STRANGE:
The final sentence seeks the exact point “where a cultural description ends and an executable operation begins.”

The sources keep moving that point.

QUESTION:
What can actually be stated rigorously without reinstalling the metaphors the project set out to destroy?

DEEPER QUESTION:
Could OPERATIVE DESCRIPTION be the larger genus whose species include programs, prompts, protocols, performatives, statecharts, and norms?

MECHANISM:
representation
→ receiver
→ uptake conditions
→ licensed behavior relation
→ realization
→ observable consequence.

FORMAL SHIFT:
<DESCRIPTION>
→ <INTERPRETABLE DESCRIPTION>
→ <OPERATIONALLY SPECIFIED DESCRIPTION>
→ <EFFECTIVELY REALIZABLE DESCRIPTION>
→ <AUTHORIZED / ACTIVATED DESCRIPTION>
→ <OBSERVABLE CONSEQUENCE>

SOURCE FORMALISM:
No single source supplies this ladder.

OUR FORMALIZATION:
[OUR FORMALIZATION — NOT SOURCE SYNTAX]

Replace the binary:

    DESCRIPTION | PROGRAM

with discriminators:

    FORMATION
    INTERPRETATION
    EFFECTIVITY
    TRANSITION TYPE
    ENVIRONMENT
    AUTHORITY
    REALIZATION
    OBSERVATION
    META-MUTABILITY

Then ask of any symbolic object:

    WHAT EXACTLY CAN THIS REPRESENTATION MAKE HAPPEN,
    THROUGH WHAT RECEIVER,
    UNDER WHAT CONDITIONS,
    WITH WHAT DEGREE OF FORMAL SPECIFICATION?

TENSION:
The broader category risks dissolving the useful technical specificity of “programming language.”

That word should therefore remain narrow where engineering precision matters.

MISSING:
A final criterion for PROGRAM as opposed to OPERATIVE DESCRIPTION.

BOUNDARY:
[OUR FORMALIZATION — NOT SOURCE SYNTAX]
The evidence no longer supports deterministic execution as the universal boundary.

It does support the methodological demand that every claimed operative analogy identify:
receiver,
state,
transition,
authority,
and realization rather than relying on words such as “code” or “program.”

CITATION TRAIL:
program/data duality.
probabilistic semantics.
protocol semantics.
speech-act uptake.
reflection.
prompt/tool execution.

TEST:
Take every occurrence of:

CODE
PROGRAM
EXECUTE
CONTROL
RULE

in the cultural and LLM corpus.

For each require five receipts:

    WHAT IS REPRESENTED?
    WHO/WHAT RECEIVES IT?
    WHAT TRANSFORMATION IS LICENSED?
    WHAT CONDITIONS ACTIVATE IT?
    WHAT OBSERVABLE DIFFERENCE FOLLOWS?

Reject the analogy only when those receipts fail—not merely when the transition is nondeterministic.
