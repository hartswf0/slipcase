TITLE:
Midway’s player is denied authorship not because the player lacks causal control but because the machine prestructures the reachable expressive space.

SOURCE:
Midway Manufacturing Co. v. Artic International, Inc. — 704 F.2d 1009 (7th Cir. 1983).

PASSAGE:
[PARAPHRASE]
Midway acknowledges player input changes sequences but emphasizes the player cannot create arbitrary sequences; the system limits reachable audiovisual possibilities.

RESEARCH OBJECT:
REACHABLE EXPRESSIVE SPACE.

LOCAL MOVE:
Ask not only CAN USER MAKE PATH GO OTHERWISE? but CAN USER INTRODUCE DIFFERENCES THE SYSTEM DID NOT ALREADY STRUCTURE AS REACHABLE?

SOURCE TERMS:
player
control

WHAT BECAME STRANGE:
Strong steering can occur while the system-authored possibility space remains unchanged.

QUESTION:
How does a generative-AI user differ from Midway’s player if the pretrained model likewise determines an enormous but bounded possibility space?

DEEPER QUESTION:
Does authorship require selecting trajectories, modifying the possibility space, or introducing independently originated constraints into it?

MECHANISM:
G defines Ω_G; actions a_t navigate to y∈Ω_G; steering need not modify Ω_G.

FORMAL SHIFT:
<TRAJECTORY CONTROL> → <CONTROL RELATIVE TO PRESTRUCTURED POSSIBILITY SPACE>

Court reasons player selects among system-allowed sequences.

Generative models synthesize outputs rather than simply store finished sequences; Midway cannot be transferred literally.

MISSING:
A measure of how user constraints modify conditional possibility distributions rather than merely sample within them.

BOUNDARY:
Counterfactual steering alone does not establish authorship.
