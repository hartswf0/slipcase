RETENTION-005-T-D

TITLE:
A model glitch can become craft knowledge, making technical improvement capable of destroying an artistic technique.

SOURCE:
Minsuk Chang et al. — “The Prompt Artists” — 2023.

PASSAGE:
[PARAPHRASE]
Some practitioners deliberately identify and reuse model glitches to create distinctive artistic styles.

RESEARCH OBJECT:
ERROR CAN BECOME AFFORDANCE.

LOCAL MOVE:
Separate craft from technical correctness.

SOURCE TERMS:
glitch
artistic style
prompt artists
model
community of practice
unique output

WHAT BECAME STRANGE:
A model update that fixes an error can culturally function as destruction of an instrument.

QUESTION:
Who decides whether anomalous model behavior is a defect to remove or a capability on which a practice depends?

DEEPER QUESTION:
Can generative-model maintenance create cultural obsolescence analogous to changing the physical affordances of an artistic medium?

MECHANISM:
M1 has repeatable glitch g; artist learns p_g→g→style S; vendor updates M1→M2 and removes g; p_g no longer produces S.

FORMAL SHIFT:
<BUG> → [PRACTITIONER APPROPRIATION] → <TECHNIQUE> → [MODEL UPDATE] → <LOST TECHNIQUE>

SOURCE FORMALISM:
NONE

OUR FORMALIZATION:
[OUR FORMALIZATION — NOT SOURCE SYNTAX]
Skill(p,g|M_v) is version-indexed; SkilledUnder(M1) does not entail SkilledUnder(M2).

TENSION:
Artists have long used contingent defects; differences include speed, remote substrate control, and inability to preserve cloud versions.

MISSING:
Documented cases where provider updates destroyed repeatable generative techniques.

BOUNDARY:
Technical improvement and artistic improvement are independently evaluable.
