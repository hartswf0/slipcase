ZETTEL

ID:
PLAYER-001

TITLE:
High causal influence over a realized path can remain navigation inside a possibility space structured by somebody else.

SOURCE:
Midway Manufacturing Co. v. Artic International, Inc. — 704 F.2d 1009 — U.S. Court of Appeals for the Seventh Circuit — 1983 — especially 704 F.2d at 1012.

SOURCE URL:
https://law.justia.com/cases/federal/appellate-courts/F2/704/1009/107395/

PASSAGE:
[PARAPHRASE]
Midway recognizes that a player changes which images occur, but rejects player authorship of the audiovisual sequence because the player cannot create any sequence desired and can only select among sequences the game permits.

RESEARCH OBJECT:
NAVIGATION IS NOT POSSIBILITY-SPACE AUTHORSHIP.

LOCAL MOVE:
Pressure-test “call the shot.” A player can intentionally and skillfully alter trajectories while the legally significant expressive space remains structured upstream.

SOURCE TERMS:
player
control
limited number of sequences
audiovisual work
stored images

WHAT BECAME STRANGE:
Counterfactual control is too broad: it can identify performance without identifying authorship.

QUESTION:
What must a generative-system user do beyond navigating a prestructured possibility space for an expressive difference to be attributable upstream to the user?

DEEPER QUESTION:
Is constraining a learned possibility distribution materially different from merely selecting one route through it?

MECHANISM:
System G structures reachable expressive space Ω_G. User action selects y∈Ω_G. Strong trajectory control can occur without changing Ω_G or introducing independent constraints.

FORMAL SHIFT:
<CAN MAKE OUTPUT GO OTHERWISE> → <WHAT STRUCTURES THE SET OF REACHABLE DIFFERENCES?>

SOURCE FORMALISM:
NONE

OUR FORMALIZATION:
[OUR FORMALIZATION — NOT SOURCE SYNTAX]
Separate Navigate_h(Ω_G), Constrain_h(Ω_G), and Modify_h(Ω_G). These are distinct causal roles.

TENSION:
Modern generative systems synthesize rather than retrieve a finite stored set of finished sequences, so Midway’s technical ontology does not transfer literally.

MISSING:
A task-level method for estimating whether a human intervention merely selects within a model-induced distribution or adds a stable independently originated constraint.

BOUNDARY:
Midway is a negative analogy about control, not direct authority governing generative outputs.

CITATION TRAIL:
[[RETENTION-005-S-A-A]] → Midway → bounded player variation → navigation versus constraint.

TEST:
Compare seed changes, instruction changes, spatial conditioning, and model fine-tuning. For each ask whether the intervention only changes which state is reached or changes the structure of the reachable distribution itself.
