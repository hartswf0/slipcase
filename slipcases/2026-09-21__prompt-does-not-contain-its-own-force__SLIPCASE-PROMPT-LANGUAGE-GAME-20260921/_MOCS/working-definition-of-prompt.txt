017. Put-That-There Tests Pointing Continuously but Reference Commitment Discretely
    ID: 20260921-put-that-there-has-continuous-and-discrete-tests-before-action
    WHAT BECAME STRANGE: There is no single “interpretation moment.” One layer is continuously visible before language arrives; another binding occurs when a deictic token is spoken; another consequence appears only after action.
    DEEPER QUESTION: Can correspondence be made easier to debug by showing the exact instant at which ambiguous evidence becomes a binding that downstream operations must obey?
