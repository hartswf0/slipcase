WHAT THE TOPOLOGY REVEALS
1. The densest conceptual crossing is lineage/provenance: social reuse, temporal cognition, external state, versioning, and repository practice all converge there.
2. A second bridge joins epistemic prompting to community experimentation: outputs can function as evidence rather than merely artifacts.
3. Current infrastructure pushes the unit away from a user-written string toward an execution event assembled from context, tools, versions, tests, and references.
4. The strongest unresolved ghost is [[SCGAI-2024]], an inherited parent-address used before a concrete source card with that ID existed. It is preserved rather than silently normalized.
5. The new paper spine therefore runs from social construction → lineage → temporal cognition → effective context → version drift → routed memory → prompt receipts.
