TITLE:
A sufficiently comprehensive prompt becomes an attractive nuisance.

SOURCE:
OpenAI — “Harness engineering: leveraging Codex in an agent-first world” — February 11, 2026 — https://openai.com/index/harness-engineering/

PASSAGE:
[QUOTE] “give Codex a map, not a 1,000-page instruction manual.”

RESEARCH OBJECT:
Current agent engineering challenges maximal prompt constitutions: giant instruction files consume scarce context, flatten priorities, become stale, and are hard to verify. A smaller navigational layer can route the system to maintained sources of truth.

LOCAL MOVE:
Replace PROMPT AS COMPLETE LAWBOOK with PROMPT AS ROUTING SURFACE.

SOURCE TERMS:
context; map; instruction manual; system of record; structured docs; stale rules; cross-links; freshness; verification

WHAT BECAME STRANGE:
Every successful correction creates pressure to append another invariant. Without subtraction, recursive prompt development can produce constitutional obesity: more knowledge, less guidance.

QUESTION:
When should a learned constraint remain in the active prompt, and when should it become an addressable external source?

DEEPER QUESTION:
Could prompt architecture be treated as an information-routing problem rather than a prose-writing problem?

MECHANISM:
failure → rule appended → context grows → priorities flatten → stale rules accumulate → retrieval precision falls → compensatory rules added; alternative: small control surface → retrieve relevant source → execute → validate.

FORMAL SHIFT:
MASTER PROMPT=Σ ALL KNOWN INSTRUCTIONS becomes CONTROL PROMPT=ROUTER(PURPOSE, INVARIANTS, SOURCE INDEX, RETRIEVAL RULES).

SOURCE FORMALISM:
OpenAI describes replacing a large AGENTS.md manual with a short map into a structured repository knowledge base/system of record.

OUR FORMALIZATION:
[OUR FORMALIZATION — NOT SOURCE SYNTAX]
PROMPT SEDIMENTATION = accumulation of historically reasonable instructions until their coexistence reduces present intelligibility.

TENSION:
Genealogy requires remembering more than execution should necessarily read. ARCHIVE and ACTIVE PROMPT must separate without severing lineage.

MISSING:
A promotion/demotion rule deciding whether a correction becomes core invariant, conditional module, retrievable documentation, test, historical note, or obsolete fossil.

BOUNDARY:
The source concerns software-engineering agents; generalized prompt sedimentation is [OUR INFERENCE].

TEST:
